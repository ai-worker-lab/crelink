# NNNN 제목

- 단계: 에픽 | 티켓 | 하위 티켓 (에픽 파일은 docs/work/epics/에 둠)
- 역할: 티켓·하위 티켓만. .omp/agents의 agent 이름이며 파일은 docs/work/<역할>/에 둠
- 상위: 하위 티켓은 필수, 티켓은 에픽 번호 또는 줄 삭제, 에픽은 줄 삭제
- 선행: 먼저 끝나야 하는 번호. 없으면 줄 삭제
- 상태: 분류 대기
- 종류: 기능 | 결함 | 유지보수 | 운영 | 제품 결정
- 우선순위: P0 | P1 | P2 | P3
- 작성일: YYYY-MM-DD

## 목적

어떤 사용자 문제·위험·품질 비용을 줄이는지 적습니다.

## 수용 기준

- [ ] 완료를 관찰할 수 있는 조건. 에픽은 사용자 관점의 통합 동작, 티켓은 해당 역할의 결과와 계약을 적습니다.
