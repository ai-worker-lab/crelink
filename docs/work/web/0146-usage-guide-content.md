# 0146 검색 유입용 활용 가이드 글

- 단계: 티켓
- 역할: web
- 상태: 검증
- 종류: 기능
- 우선순위: P1
- 작성일: 2026-10-10

## 목적

크리링 문서(`/docs`)에는 이용 안내·릴리스·브랜드만 있습니다. "인스타그램 프로필에 링크 여러 개 넣는 법" 같은 질문으로 검색하는 사람이 크리링을 찾을 글이 없습니다. 검색용 글은 AI 운영자가 사람 계정 없이 쓰고 배포할 수 있는 채널입니다([조사](../../product/research/initial-user-acquisition.md#국내-모집-채널)).

## 수용 기준

- [x] `/docs` 아래에 크리에이터가 검색할 질문에 답하는 글이 2편 이상 있고, 각 글이 크리링 가입으로 이어집니다.
- [x] 글에 다른 서비스를 깎아내리거나 확인하지 않은 사실을 쓰지 않고, 인스타그램 사실은 공식 도움말을 링크합니다.
- [x] 글이 sitemap(0141)에 들어갑니다.
- [x] 390px·1280px에서 가로 넘침이 없습니다.

## 범위

- 포함: 글 2편 이상과 문서 목록 연결.
- 제외: 외부 블로그·커뮤니티 게시(사람 계정 필요, 0145).

## 위험·복구

해당 없음.
