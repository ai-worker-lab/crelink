# 0023 SNS 채널 공식 아이콘

- 단계: 티켓
- 역할: web
- 상태: 검증
- 종류: 기능
- 우선순위: P1 (AI 제안)
- 작성일: 2026-10-06

## 목적

SNS 채널이 플랫폼 아이콘 없이 글자 표시(IG·YT·TT 등)로만 보였습니다. 각 서비스의 공식 컬러 브랜드 아이콘을 자산으로 두고 랜딩과 편집 화면에 반영합니다(PRD R12 "SNS 계정 주소를 넣으면 해당 SNS 아이콘이 붙는다"). 아이콘은 디자인 시스템의 영향을 받지 않습니다.

## 수용 기준

- [x] 플랫폼 8종(인스타그램·유튜브·틱톡·네이버 블로그·X·스레드·페이스북·기타) 아이콘이 `apps/web/public/icons/sns/`에 있고, 공식 출처·가이드라인·이용 조건이 문서에 있다.
- [x] 브랜드 아이콘은 원본 색 그대로 표시되고 토큰·테마·필터가 적용되지 않는다(`other` 제외).
- [x] 랜딩 SNS 줄과 `/me` SNS 편집 행에 플랫폼 아이콘이 보인다.
- [ ] 틱톡 사용 허가 확인(사용자 결정 필요, 아래 위험).
- [x] `pnpm verify` 통과, `pnpm e2e` 통과.

## 범위

- 포함: `apps/web/**`(자산·컴포넌트·스타일·문서), 외부 의존 문서.
- 제외: 크리링 고유 디자인(0020).

## 위험·복구

상표: 로고 상표권은 각 회사에 있습니다. 공식 파일을 변형하지 않고 가이드라인 값으로만 표시합니다. 남은 위험(틱톡 서면 허가, 네이버 블로그 전용 키트 없음 등)은 [SNS 채널 아이콘 문서](../../../apps/web/docs/sns-icons.md#남은-위험검수-전-확인)에 있습니다.

## 진행 기록

- 2026-10-06: 생성·착수(브랜치 `work/0023-sns-channel-icons`). 사용자 요구 "sns 채널별로 아이콘이 없다. 공식 아이콘을 확인하고 asset으로 추가하고 반영".
- 2026-10-06: 구현. Simple Icons 16.34.0(CC0-1.0) SVG를 복사(각 아이콘의 공식 출처·가이드라인 URL은 패키지 데이터에서 확인해 문서화), 기타는 기존 링크 아이콘 모양. `SocialIcon`(CSS mask, 글자색 단색, `aria-hidden`), `SOCIAL_PLATFORM_LABELS`의 `mark` → `icon`.
- 2026-10-06: 검증. 자산 8개가 개발 서버에서 `image/svg+xml` 200. 390px에서 랜딩 SNS 줄·`/me` SNS 편집 행에 8종 아이콘 표시를 스크린샷으로 확인. 첫 `pnpm e2e`는 6개 모두 실패했는데, 원인은 실행 중이던 웹 개발 서버의 하위 서버가 브랜치 전환(`main` fast-forward 중 0019 이전 `next.config.ts`가 잠시 체크아웃됨) 때 `distDir` 없이 다시 떠 `.next`를 쓰던 것(로그 `.next/server/app/me/page.js` `MODULE_NOT_FOUND`)으로 이 변경과 무관. `make web-restart` 뒤 `.next-dev` 사용 확인, 개발 서버를 띄운 채 `pnpm verify` 8단계 통과 → `/`·`/me`·`/p/{id}` 200, `pnpm e2e` 6 passed, `pnpm smoke` 5 passed.
- 2026-10-06: 사용자 결정 변경: 공식 아이콘은 컬러여야 하고 디자인 시스템 영향을 받으면 안 됨(각 서비스 검수 문제). 채널별 조사 에이전트 7개를 병렬로 돌려 공식 자산·가이드라인을 조사한 뒤 병합. 결과: 인스타그램(공식 그라디언트 글리프 PNG 512px로 축소), 유튜브(공식 빨강 PNG), 틱톡(공식 Social Icons 원형 SVG), 네이버 블로그(블로그 현행 공식 웹 아이콘 PNG 192px, 전용 배포 키트 없음), X(공식 흰 SVG + 검정 타일), 스레드(공식 검정 SVG + 흰 타일), 페이스북(공식 파란 로고 PNG). 제3자 Simple Icons 파일은 모두 교체·삭제. `SocialIcon`을 `<img>` 원본 표시로 변경, 브랜드 크기·타일을 `.social-icon--*` 고정값으로, `design/system/DESIGN.md`에 적용 제외 규칙 추가. 390px 스크린샷으로 8종 원색 표시 확인.
