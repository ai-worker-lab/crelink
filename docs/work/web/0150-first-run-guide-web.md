# 0150 관리 화면 첫 사용 안내 카드 구현

- 단계: 티켓
- 역할: web
- 상태: 준비
- 종류: 기능
- 우선순위: P1
- 작성일: 2026-10-10

## 목적

[0143](../designer/0143-first-run-guide-design.md) 시안대로 빈 랜딩 관리 화면(`페이지 편집`)에 3단계 시작 안내 카드(① 링크나 포트폴리오 1개 추가 → ② 내 크리링 링크 복사 → ③ 인스타그램 프로필에 붙여 넣기)를 구현합니다. 실사용자 0/100이고 가입한 크리에이터 4명이 모두 링크·포트폴리오가 없어, 가입→실사용자 전환이 지금 가장 큰 병목입니다.

## 수용 기준

- [ ] [인계 문서](../../../design/first-run-guide/handoff.md)의 화면 위치·상태(A~E)·전이·문구 원문·반응형(1280px·390px)대로 카드가 보입니다.
- [ ] ①은 서버 편집 상태의 방문자에게 보이는 링크·포트폴리오 합으로 판정하고, ②·③·닫기는 기기 로컬 저장만 씁니다. 새 API·DB·개인정보 수집이 없습니다.
- [ ] 인스타그램 안내는 사용자가 직접 붙여 넣는 방법만 알리고, 크리링이 대신 등록하지 않는다는 문구가 있습니다.
- [ ] 키보드 포커스·스크린리더 문구가 인계의 접근성 절과 맞고, 로컬 인스턴스에서 390px·1280px 화면을 확인했습니다.

## 범위

- 포함: `apps/web` 관리 화면 카드 구현, 웹 단위 시험, 웹 변경 기록.
- 제외: API·DB 변경, 이메일·알림 발송, 인계 `미결정` 항목의 정책 변경(개인정보 처리방침 문구 추가는 필요하면 별도 work item).

## 위험·복구

로컬 저장 키 이름이 바뀌면 이미 닫은 카드가 다시 보일 수 있습니다. 키는 인계의 `crelink.firstRunGuide.<publicId>`를 그대로 씁니다. 문제가 생기면 PR revert로 되돌립니다(서버 상태 없음).
