## 목적

## 수용 기준

- [ ] `페이지 편집` 이벤트 띠와 `외부 링크` 패널 신청 줄이 디자인 인계(`design/slot-event/handoff.md`)의 상태 전부(열림·미신청, 신청 중, 완료, 실패 409·404·네트워크, 신청함, 끝남·미신청)를 그립니다. 확인: 로컬에서 각 상태 화면, 0125 E2E.
- [ ] 신청은 `POST /api/me/slot-event/entry` 뒤 `reload()`로 한도 배지가 보너스를 반영합니다(`보이는 링크 n/10`).
- [ ] 한도가 찬 안내 문구가 미신청·열림이면 이벤트 안내를 더합니다. 확인: `limits.ts` 단위 테스트.
- [ ] 390·1280px 가로 넘침 없음. `pnpm --filter @crelink/web lint`·`typecheck`·`test` 통과.
