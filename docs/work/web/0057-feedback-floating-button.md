# 0057 의견 보내기를 머리글에서 오른쪽 아래 떠 있는 버튼으로

- 단계: 티켓
- 역할: web
- 상태: 검증
- 종류: 기능
- 우선순위: P2 (AI 제안)
- 작성일: 2026-10-08

## 목적

`의견 보내기`(0052 `FeedbackButton`)가 관리 화면(`/me/landings/{publicId}/…`)과 운영자 화면(`/admin`) 머리글에서 `공개 페이지 열기`·`로그아웃`과 나란히 있습니다. 사용자는 계정·이동 버튼 사이에 있는 것이 어색하다고 보고 오른쪽 아래에 떠 있는 버튼으로 옮기기로 했습니다(2026-10-08 사용자 결정).

## 수용 기준

- [x] `의견 보내기`가 머리글에서 빠지고, 로그인 화면(관리 화면·`/me` 오류 화면·운영자 화면) 오른쪽 아래에 고정된 버튼으로 보이며 누르면 지금처럼 Sentry 의견 창이 열린다.
- [x] 1023px 이하에서는 이름 있는 아이콘 버튼이고, 아래 가운데 `미리보기` 버튼과 겹치지 않는다(390px·320px). 하단 시트·미리보기 대화상자가 열리면 그 아래에 가려진다.
- [x] 버튼이 페이지 마지막 내용을 가리지 않는다(맨 아래까지 스크롤했을 때). 1280px·1100px·390px에서 가로 넘침이 없다.
- [x] Sentry가 꺼진 빌드(DSN 없음)에서는 지금처럼 그리지 않는다.

## 범위

- 포함: `apps/web/src/components/FeedbackButton.tsx`, 쓰는 화면 세 곳(`app/me/landings/[publicId]/layout.tsx`, `app/me/page.tsx`, `components/admin/AdminShell.tsx`), `styles.css`, 웹 변경 기록.
- 제외: 의견 창 내용·Sentry 설정, 공개 화면(랜딩·홈)에 의견 버튼 두기, 관리 화면 정보 구조(0056 시안).

## 위험·복구

화면 배치만 바뀝니다. 문제가 생기면 이 커밋을 되돌립니다.

## 진행 기록

- 2026-10-08: 생성, 브랜치 `work/0057-feedback-floating-button`.
- 2026-10-08: 구현. `FeedbackButton`을 머리글 세 곳에서 빼 화면 틀 맨 끝에 두고 `.feedback-fab`(1023px 이하 아이콘 버튼), 버튼이 있는 화면의 `.app-main` 아래 여백, 1024px 이상 미리보기 프레임 높이에서 버튼 자리 72px를 뺌(처음 1280×800·1100×800 화면에서 버튼이 프레임 오른쪽 아래 모서리를 덮은 것을 스크린숏으로 찾아 고침). 확인(Node 24.20.0): 가짜 DSN(`NEXT_PUBLIC_SENTRY_DSN=http://public@127.0.0.1:9/2`)으로 웹을 잠시 띄워 임시 Playwright 시나리오(확인 뒤 지움) — 관리 화면·`/admin` 머리글에 버튼 없음, 오른쪽 아래 버튼(1280px `x 1113 y 728 142×48`), 390px 아이콘 버튼 `x 326`·`미리보기` 버튼 `x 132~257`, 320px `x 256`·`97~222`로 겹치지 않음, 네 폭과 `/admin` 390px 가로 넘침 없음, 누르면 의견 창(내용 입력란) 열림, 미리보기 대화상자가 버튼을 덮음, 스크린숏으로 프레임·마지막 카드를 덮지 않음 확인. 이후 웹은 원래 pm2 실행(DSN 없음)으로 되돌림. `pnpm verify --fast` 6단계 통과, `pnpm e2e` 8건 통과(DSN 없는 로컬이라 버튼은 그려지지 않음).
