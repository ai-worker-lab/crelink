## 목적

BFF 헤더 전달과 페이지 전환, 초대 수락, 공동 관리자 화면을 구현하고 처리방침을 고칩니다.

## 수용 기준

- [ ] 관리 화면의 모든 API 호출이 대상 페이지 헤더를 보내고 BFF가 형식 검증 후 전달합니다.
- [ ] 공유 화면의 저장이 개인 페이지를 바꾸지 않음을 BFF를 통과하는 시험으로 확인합니다.
- [ ] 페이지 전환, 초대 수락, 공동 관리자 메뉴, 편집자 숨김, 처리방침이 설계와 같습니다.
- [ ] `pnpm verify`가 통과합니다.

## 범위

- 포함: `apps/web/**`.
- 제외: API, 시각 토큰 추가, 쿠키에 활성 페이지 저장, `window.confirm` 신규 사용.

## 위험·복구

처리방침 밖 처리가 없도록 기능과 같은 배포로 나갑니다. 문제가 생기면 직전 릴리스로 롤백합니다.
