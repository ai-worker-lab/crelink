## 목적

링크 슬롯 +5 이벤트 기술 설계의 티켓 분해 0124입니다. 운영자가 이벤트 기간을 정하고 신청자 목록·신청 수를 봅니다.

## 수용 기준

- [x] `/admin/slot-event`: 기간 카드(상태 배지, 시작·끝 입력 Asia/Seoul, 저장, 400 오류 문구), 신청 수, 신청자 표(신청일시·이메일·표시 이름·단축 주소·상세 링크, 최신순 20개 쪽 넘김, 빈 상태), 불러오기 오류(`AdminShell`). 운영자 메뉴에 `이벤트`.
- [x] `/admin/creators/{userId}` 한도 도움말이 `무료 5 + 추가 슬롯 n + 이벤트 5`로 나뉘고 신청일을 보입니다.
- [x] 390·1280px 가로 넘침 없음. `pnpm --filter @crelink/web lint`·`typecheck` 통과. 확인: 0125 E2E.
