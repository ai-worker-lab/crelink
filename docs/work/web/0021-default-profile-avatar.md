# 0021 기본 프로필 이미지

- 단계: 티켓
- 역할: web
- 상위: 0014
- 상태: 완료
- 종류: 기능
- 우선순위: P1 (AI 제안)
- 작성일: 2026-10-06

## 목적

크리에이터가 프로필 사진을 올리지 않으면 랜딩페이지 머리가 비어 보입니다. 사진이 없을 때 기본 프로필을 보여 줍니다(PRD R17).

## 수용 기준

- [x] 프로필 사진이 없는 `/p/{publicId}`에 기본 프로필이 보이고, 사진이 있으면 사진이 보인다.
- [x] `/me` 프로필 사진 자리에 사진이 없으면 기본 프로필이 보이고, 올리면 미리보기로 바뀐다.
- [x] `pnpm verify`, `pnpm e2e` 통과, 390px·1280px 가로 넘침 없음.

## 범위

- 포함: `apps/web/**`(기본 프로필 컴포넌트·스타일), E2E 단언 추가.
- 제외: API 응답 변경(`avatarUrl`은 그대로 null), 기본 프로필 이미지의 최종 디자인(0020).

## 위험·복구

해당 없음

## 연결

- 요구: [PRD R17](../../product/crelink.md#요구사항)
- 디자인: 기본 프로필 모양은 임시이며 0020에서 고유 디자인으로 바꿉니다.

## 진행 기록

- 2026-10-06: 생성. 사용자 요구 "사용자 프로필 이미지가 없을 경우 기본 프로필을 추가하자".
- 2026-10-06: 구현·검증. `DefaultAvatar`(토큰 색 인라인 SVG, `aria-hidden`), 랜딩 머리와 `/me` 프로필 사진 자리(`ImageField` `placeholder`). E2E 단언 추가(빈 랜딩에 기본 프로필, 사진 업로드 뒤 기본 프로필 사라짐, 사진 있는 랜딩엔 없음). `pnpm verify --fast` 통과, `pnpm e2e` 5 passed(390px 확인 포함), 390px 랜딩 화면을 스크린샷으로 확인.
