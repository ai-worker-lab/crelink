# 0247 채널별 짧은 주소 웹

- 단계: 티켓
- 역할: web
- 선행: 0246
- 상태: 검증
- 종류: 기능
- 우선순위: P1
- 작성일: 2026-11-10

## 목적

관리 화면에서 채널과 노출 위치를 고르기만 하면 `{SHORT}/s/{code}` 주소를 만들고 복사·보관하게 하고, 공개 페이지가 `via`로 들어온 방문의 채널 UTM을 기록하게 합니다.

## 수용 기준

설계 [채널별 짧은 주소](../../specs/channel-links.md#화면-상한-메뉴-1개화면-1개-새-디자인-문서-없음)의 화면과 수용 기준 9·11을 따릅니다.

- [x] `채널 주소` 메뉴와 `/me/landings/[publicId]/channels` 화면이 있고, 채널·노출 위치·캠페인으로 주소 만들기, 복사, 보관이 동작합니다.
- [x] BFF 허용 목록에 목록·생성·보관이 메서드별로 들어가 있습니다.
- [x] 공개 페이지가 `via`를 한 번만 조회해 API의 `utm`을 `VisitorTracker`에 넘기고, 통과 표시가 없으면 UTM 없이 `shortUrl`로 돌려보내 루프가 없습니다.
- [x] 390×844·1280×900에서 ego-browser로 만들기·복사·보관을 확인하고 가로 넘침이 없습니다.

## 범위

- 포함: `apps/web/**`(메뉴·화면·BFF 규칙·오류 문구·`via` 처리·시험), 웹 문서와 변경 기록.
- 제외: 새 디자인 문서, 통계 화면 한글 라벨, 주소별 클릭 수, 직접 입력 채널, 보관 해제.

## 위험·복구

화면과 공개 랜딩의 `via` 처리만 바뀌며 데이터는 0246의 표를 씁니다. 문제가 생기면 직전 릴리스로 롤백합니다.
