# 0152 개인정보 처리방침에 관리 화면 시작 안내 로컬 저장 고지(PM 검토)

- 단계: 티켓
- 역할: web
- 상태: 분류 대기
- 종류: 제품 결정
- 우선순위: P2 (AI 제안)
- 작성일: 2026-10-10

## 목적

[0150](0150-first-run-guide-web.md)의 관리 화면 시작 안내 진행 표시는 브라우저 로컬 저장(`crelink.firstRunGuide.<publicId>`)에만 둡니다. 서버로 보내지 않는 참/거짓 값이며 처리방침의 기존 브라우저 저장 고지와 실제 동작을 PM이 검토해 한 줄 추가 여부를 결정합니다([인계 미결정 1](../../../design/first-run-guide/handoff.md#미결정)). 2026-10-12 위임에 따라 지출/결제 없는 일반 제품/고지 판단을 별도 사람 승인으로 미루지 않으며 수집·목적 변경이나 개인정보 보호 위반을 허용하는 것은 아닙니다.

## 수용 기준

- [ ] PM이 실제 로컬 저장 동작·현재 처리방침·법적 고지 조건을 확인하고 한 줄 추가 여부와 근거를 결정합니다. 준수 근거 부족은 검토 선행 조건, 유료 자문은 비용 사전 승인으로 구분합니다.
- [ ] 추가로 정하면 `쿠키` 구역에 "관리 화면 시작 안내 진행 표시를 이 기기 브라우저에만 저장해요(서버로 보내지 않음)." 같은 한 줄과 시행일·변경 이력을 고칩니다.

## 범위

- 포함: 처리방침 `쿠키` 구역 한 줄, 웹 변경 기록.
- 제외: 수집 항목·목적 변경, 서버 저장.
