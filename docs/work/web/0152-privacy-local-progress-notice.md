# 0152 개인정보 처리방침에 관리 화면 시작 안내 로컬 저장 고지(사람 결정 필요)

- 단계: 티켓
- 역할: web
- 상태: 분류 대기
- 종류: 제품 결정
- 우선순위: P2 (AI 제안)
- 작성일: 2026-10-10

## 목적

[0150](0150-first-run-guide-web.md)으로 관리 화면 시작 안내 카드의 ②·③·닫기 진행 표시를 브라우저 로컬 저장(`crelink.firstRunGuide.<publicId>`)에만 둡니다. 서버로 보내지 않는 참/거짓 값이라 개인정보 수집은 아니라고 봤지만, 개인정보 처리방침 `쿠키` 구역(`apps/web/src/app/(public)/privacy/page.tsx` `privacy-cookies`)은 브라우저 저장 항목을 모두 알리고 있습니다. 투명성을 위해 같은 구역에 한 줄을 더할지 사람이 정합니다([인계 미결정 1](../../../design/first-run-guide/handoff.md#미결정)).

## 수용 기준

- [ ] 사용자가 한 줄 추가 여부를 정합니다. 개인정보 처리방침 문구 변경은 AI 운영자 위임 범위(헌장 지킬 규칙 4)와 겹칠 수 있어 사람 결정으로 둡니다.
- [ ] 추가로 정하면 `쿠키` 구역에 "관리 화면 시작 안내 진행 표시를 이 기기 브라우저에만 저장해요(서버로 보내지 않음)." 같은 한 줄과 시행일·변경 이력을 고칩니다.

## 범위

- 포함: 처리방침 `쿠키` 구역 한 줄, 웹 변경 기록.
- 제외: 수집 항목·목적 변경, 서버 저장.
