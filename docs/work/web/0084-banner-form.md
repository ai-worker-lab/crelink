# 0084 배너 폼·초안 미리보기

- 단계: 티켓
- 역할: web
- 상위: 0063
- 선행: 0083, 0080
- 상태: 완료
- 종류: 기능
- 우선순위: P1
- 작성일: 2026-10-09

## 목적

광고 블록·배너 슬롯 기술 설계의 티켓 분해 T16입니다. 요구는 R21 ②④입니다.

## 수용 기준

- [x] 배너 폼: 필드·검사·저장·삭제 확인, 배너 초안 규칙(미리보기 덮어 그리기), 정지 이미지 올리기. 390·1280px.

## 범위

- 포함: 위 수용 기준. 세부는 [기술 설계](../../specs/crelink-ad-banner.md)의 해당 절을 따릅니다.
- 제외: 다른 티켓의 범위.

## 위험·복구

기술 설계 `위험과 스파이크`·`통합과 배포 순서`를 따릅니다.
