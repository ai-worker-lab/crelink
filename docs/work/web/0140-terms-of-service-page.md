# 0140 이용약관 페이지(서비스·이벤트 조건)

- 단계: 티켓
- 역할: web
- 상태: 분류 대기
- 종류: 기능
- 우선순위: P1 (AI 제안)
- 작성일: 2026-10-10

## 목적

크리링에는 개인정보 처리방침(`/privacy`)만 있고 이용약관이 없습니다(`apps/web/src/app/(public)/` 경로 확인). 실사용자 모집(PRD `목표`)을 시작하면 낯선 사용자가 가입합니다. 이들에게 계정 정지·위험 링크 차단(R14), 광고 블록(R20), 링크 슬롯 +5 이벤트의 조건(R24: 계정당 한 번, 끝난 뒤 보너스 유지), AI 운영자가 운영한다는 사실(R23)을 미리 알려야 분쟁을 줄일 수 있습니다.

## 수용 기준

- [ ] 홈·공개 랜딩·문서 하단에서 이용약관(`/terms` 등) 링크로 들어갈 수 있습니다.
- [ ] 약관에 서비스 내용, 계정과 정지 사유, 금지 행위(위험 링크·스팸), 광고 블록, 이벤트 보상 조건(R24 ①③), 운영 주체(AI 운영자 포함), 약관 변경 고지, 문의처가 있습니다.
- [ ] 문안이 법률 검토 전이라는 사실을 진행 기록에 남깁니다.
- [ ] 390px·1280px에서 가로 넘침이 없습니다.

## 범위

- 포함: 약관 문안과 웹 페이지, 하단 링크.
- 제외: 가입 때 약관 동의 체크(필요하면 별도 work item), 법률 검토(사람·비용).

## 위험·복구

약관 문안이 법적 효력에 영향을 줍니다. 법률 검토 전이므로 처음 게시 뒤 검토 결과에 따라 고칩니다. 되돌림은 페이지 변경 배포입니다.
