## 목적

에픽 0175의 웹 화면을 바꿉니다. 링크 한도 문구를 전체 50개 기준으로 고치고, 운영자 추가 슬롯·링크 슬롯 이벤트 화면을 걷어 내며, 운영자 플랫폼 스위치와 편집 화면 크리에이터 스위치를 더합니다.

## 수용 기준

- [ ] 관리 화면 링크 한도 배지·안내가 `CRELINK_LIMITS.totalLinks`(숨긴 링크 포함) 기준이고 유료·추가 슬롯·이벤트 문구가 없음.
- [ ] `/admin/slot-event`, 운영자 메뉴 `이벤트`, 홈 이벤트 카드, 편집 화면 이벤트 띠·신청 줄, 크리에이터 상세 추가 슬롯 폼, BFF 허용 경로가 없음.
- [ ] `/admin/ad-banners`에 플랫폼 광고 블록 스위치(기본 꺼짐), 저장 중·실패 안내.
- [ ] 편집 화면: 플랫폼 꺼짐이면 광고 블록 줄·패널·스위치 없음(링크 순서 저장은 광고 위치를 그대로 둠). 플랫폼 켬이면 광고 줄에 켜고 끄기 스위치(기본 꺼짐), 미리보기가 선택을 따름, 끌어서 옮기기 유지.
- [ ] 약관·안내 문서: 링크 50개, 광고 노출은 선택이고 수익 배분 조건은 정해지지 않음. 수익 약속 문구 없음.
- [ ] `pnpm --filter @crelink/web lint`·`typecheck`·`test` 통과, 390px·1280px 가로 넘침 없음.
