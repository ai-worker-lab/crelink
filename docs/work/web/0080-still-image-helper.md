- 역할: web

- 상태: 준비

## 목적

## 수용 기준

- [ ] 정지 이미지 도우미: `ImageField`의 3:1 미리보기·안내 문구 prop, `animated` 응답이면 정지 이미지를 만들어 쌍으로 올림. 단위 테스트(자르기 크기), 브라우저 확인. 미정 1이 A·D면 만들지 않습니다.
