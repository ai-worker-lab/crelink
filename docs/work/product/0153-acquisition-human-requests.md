# 0153 모집 채널 PM 실행(기존 사람 요청 전환)

- 단계: 티켓
- 역할: product
- 상태: 준비
- 종류: 운영
- 우선순위: P1 (AI 제안)
- 작성일: 2026-10-10

## 목적

정책 갱신일은 2026-10-12, 실행 소유자는 PM입니다. 무료 홍보의 사람 결정 대기는 해제됐으며 다음 행동은 채널 규칙·무료 조건·접근 확인과 실제 실행입니다. 준비 상태는 외부 게시 완료를 뜻하지 않습니다.

실사용자 100명의 기존 단계 1·2 채널(지인 초대, 디스콰이엇, 커뮤니티 홍보 게시판, 크리링 공식 인스타그램)과 H2 검색엔진 등록 계획을 재사용합니다. 2026-10-12 사용자 결정(“외부 홍보도 자체적으로 하라. 지출, 결제만 사람 승인 필수로 한다”)으로 H1~H5의 무료 실행·회사 계정 구성·활용은 PM이 결정·실행합니다. 문안·규칙 확인표·이전 요청일과 실행 근거 원본은 [모집 채널 PM 실행 목록](../../product/acquisition-playbook.md#pm-실행-목록)에 있습니다. 과거 사람 요청은 역사 기록으로 보존하며 현재 승인 게이트로 쓰지 않습니다.

## 수용 기준

- [ ] PM이 법·약관·기존 사전 수신동의·개인정보·저작권·회사/AI 자격·무료 조건·인증/멈춤 전제를 확인한 채널을 선정하고 H1~H5의 실행 또는 미실행 근거를 원본에 기록합니다. 한 채널의 접근/동의가 없어도 가능한 무료 공개 채널을 사람 승인 없이 실행할 수 있습니다.
- [ ] H5의 무료 공식 회사 계정 구성·활용 여부를 PM이 결정하고 PRD `위험과 미정 사항`에 근거를 남깁니다. 허용된 방식의 정상 접근·검증 불가는 실제 인증/접근 blocker로 기록하며 비용 승인 대기로 분류하지 않습니다.
- [ ] 실제 실행마다 채널 규칙 URL·확인 시각, 비용 근거(확인된 0과 미확인 구분), 제출/게시/발송 시각과 확인 가능한 공개 URL, 결과(제출/검토 중/공개/거절/접근 blocker/철회)를 기록합니다. 공개와 제출을 구분하고 날짜·게시 사실·최신 사용자 수를 추정하지 않습니다. 개인 연락처·대화 원문·비밀값은 기록하지 않습니다.
- [ ] 공개 뒤 관측·철회 상태와 실제 실행 뒤 7일 가입·실사용자 지표의 측정 시각·원본을 연결합니다. 이 정책 전환만으로 실행·성과 수용 기준을 완료 처리하지 않습니다.

## 범위

- 포함: PM의 무료 외부 게시·모집·합법/동의된 개별 연락·플랫폼이 허용하는 무료 회사 계정 구성과 실행 결정, 정상 접근 전제 확인, 실행·결과·관측 기록. 전문 worker는 조사·문안·로컬 검증 결과를 PM에게 실행 인계하고 운영 credentials는 받지 않습니다.
- 제외: 신규 캠페인 산출물 작성, 사전 동의 없는 1-A 연락, 사칭·허위 후기·금지된 자동화/스팸·인증 우회·비밀값 전달/공개·데이터 파괴. 유료 광고 등 실제 지출·결제·유료 구독/크레딧·비용 발생 약정은 사람 사전 승인 없이는 실행하지 않습니다. 비용 없는 새 슬롯·이벤트 조건은 PRD/제품 결정 절차를 따르고 사람 재승인 대상으로 만들지 않습니다. 이번 문서 정책 갱신은 실제 외부 게시를 수행하거나 실행 완료 근거를 생성한 작업이 아닙니다.

## 위험·복구

문안의 사실·회사/AI 관계 표시를 지키고 규칙 확인표를 건너뛰지 않습니다. 법·약관·수신동의 등 실행 근거가 없거나 멈출 조건이 생기면 그 채널을 멈추고 PM 실행 목록과 실행 기록에 실제 blocker·거절·철회 근거를 남깁니다. 사람의 비용 승인이나 일반 허락으로 금지를 우회하지 않습니다. 기존 H1 → H3 → H4 → H5 주간 순서는 관측 기본 계획이며, PM이 실행 가능한 무료 채널을 먼저 고르면 변경 근거를 남깁니다.
