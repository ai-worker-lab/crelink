# 0147 친구 초대 보상 요구 검토

- 단계: 티켓
- 역할: product
- 상태: 분류 대기
- 종류: 제품 결정
- 우선순위: P2 (AI 제안)
- 작성일: 2026-10-10

## 목적

Linktree는 성장 대부분이 자연 유입과 사용자 추천이었다고 합니다([조사](../../product/research/initial-user-acquisition.md#linktree)). 크리링에는 추천 장치가 없습니다. 실사용자 100명의 단계 3에서 실사용자가 다른 크리에이터를 데려오게 할지, 보상(예: 링크 슬롯)을 줄지 정해야 합니다.

## 수용 기준

- [ ] 초대 방식(초대 주소, 보상 대상·조건·상한)과 반대 근거를 정리한 PRD 변경안이 있습니다.
- [ ] 법·약관 검토가 들어 있습니다: 보상을 받고 쓴 소개 글의 추천·보증 표시, Meta 스팸 정책의 참여 대가 경품 금지, 초대 메시지의 정보통신망법 제50조.
- [ ] 넣기로 하면 요구 번호와 수용 기준을 PRD에 적고 구현 work item으로 나눕니다. 넣지 않으면 이유를 남기고 `보류/종료`로 둡니다.

## 범위

- 포함: 요구 검토와 결정 기록.
- 제외: 구현.

## 위험·복구

보상을 노린 가짜 가입이 늘면 실사용자 지표가 흐려집니다. 보상 조건은 초대받은 계정이 실사용자가 된 뒤로 두는 것을 검토합니다.
