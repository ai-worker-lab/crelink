# 0041 링크 인 바이오 유사 서비스 벤치마킹(인포크링크·인링크·리틀리)

- 단계: 티켓
- 역할: product
- 상태: 검증
- 종류: 제품 결정
- 우선순위: P2 (AI 제안)
- 작성일: 2026-10-07

## 목적

크리링 디자인 시스템(0020, 스튜디오 라이트)을 웹 화면에 옮기기(0040) 전에, 사용자가 지정한 유사 서비스 세 곳의 공개 페이지 구성·편집 UX·공유·통계·시각 스타일을 확인해 디자인과 UX/UI를 부분적으로 참고할 근거를 만듭니다. PRD `유사 서비스에서 얻은 것` 절이 비어 있는 것도 채웁니다.

조사 질문: 인스타그램 크리에이터가 링크 페이지를 만들고 공유하기까지, 그리고 방문자가 링크를 누르기까지 세 서비스는 화면을 어떻게 구성했는가? 그중 크리링 MVP 화면(공개 랜딩, 링크 관리, 내 크리링)에 옮길 만한 것은 무엇인가?

끝낼 조건: 세 서비스의 공개 자료(공식 사이트·도움말·요금 페이지)로 확인할 수 있는 범위를 정리하고, 로그인이 필요한 편집 화면처럼 확인하지 못한 부분은 `미정`으로 남깁니다.

## 범위

- 제외: 디자인·코드 변경(반영은 0020·0040에서), 조사 계정에 블록 저장·외부 연동(쿠팡 파트너스 키 등).

## 진행 기록

- 2026-10-07: 생성. 사용자 요청: 유사 서비스(인포크링크 https://www.inpock.co.kr/, 인링크 https://inlink.to/, 리틀리 https://start.litt.ly/)를 먼저 조사하고 디자인·UX/UI를 부분적으로 참고한다.
- 2026-10-07: 세 서비스의 공식 사이트·도움말·요금 페이지·공개 페이지 예시(HTML의 JSON·CSS 값)·앱 스토어 평점을 조사해 `docs/product/research/link-in-bio-benchmark.md` 작성, PRD `유사 서비스에서 얻은 것` 절에서 연결. 로그인이 필요한 편집 화면과 리틀리 앱 리뷰는 확인하지 못함. 미정 5개(QR, 방문자 공유 버튼, 링크 강조, 크리에이터용 방문 수, 크리에이터 테마)는 사용자 결정 대기.
- 2026-10-07: 사용자 결정(미정 5개 모두 추천안): QR 다운로드·방문자 공유 버튼·링크 강조는 이후 버전, 크리에이터 방문 수는 보여 주지 않음(R10 유지), 크리에이터 테마는 MVP에서 열지 않음. 벤치마킹 문서 결론과 PRD 범위의 MVP 제외 항목에 반영. 디자인 시스템·0040 범위 변경은 없음.
- 2026-10-07: 사용자 요청으로 Orca 내장 브라우저에서 리틀리 편집 화면(https://app.litt.ly/page , 무료 계정, 빈 새 페이지 litt.ly/shaul)의 페이지·디자인·분석·관리·마케팅 탭, 블록 추가 목록, 페이지 설정·공유 창, 멀티 페이지·플랜 화면과 공개 페이지 데이터(`<script id="data">`)를 확인해 벤치마킹 문서에 `리틀리 편집 화면` 절을 추가하고 기능 비교·사업·결론을 보강. 새 미정 3개는 사용자 결정 대기.
- 2026-10-07: 조사 중 조사 계정에 의도하지 않은 변경이 생김. 갱신하지 않은 스냅숏 참조로 누른 클릭이 그룹 링크 레이아웃(`2 캐러셀`)·링크 나열(`접기 적용`), 단일 링크 카드(`큰 카드`), 폰트를 바꿨고, 확인하려고 누른 `페이지 추가`가 바로 하위 페이지 1개를 만듦. 모두 원래 값으로 되돌리고 공개 페이지 데이터에서 `subpages: []`·`stickers: []`·폰트 `default`·단일 링크 `smallButton`·그룹 링크 `button`/`all`을 확인. 같은 과정에서 인스타그램 로그인(OAuth) 창과 브랜드 플랜 안내 창이 열렸으나 로그인·결제는 하지 않았고 열린 탭은 닫음.
- 2026-10-07: 사용자 요청으로 Orca 내장 브라우저에서 인포크링크(베이직 플랜, 빈 페이지)와 인링크(인플루언서 계정, 링크 0개)의 편집 화면을 확인해 벤치마킹 문서에 `인포크링크 편집 화면`·`인링크 마이링크 편집 화면` 절을 추가하고 기능 비교 표·사업·결론·출처를 고침. 주요 사실: 인포크 링크 블록은 주소를 넣으면 `/api/link-metadata`로 제목·이미지를 채우지만 쿠팡 상품 주소는 HTTP 400, 인포크 `파트너스`(BETA)는 크리에이터의 쿠팡 파트너스 Access·Secret Key를 받아 상품 검색·링크 생성, 인포크 컬렉션은 2·3열 그리드만, 인링크 편집은 즉시 저장·블록 9개 끌기 정렬·자리 고정 버튼. 저장·연동은 하지 않음(인포크 링크 블록 입력은 `추가 완료` 없이 빠져나옴, 인링크는 구역만 펼치고 "모든 변경이 저장됐어요"·`되돌리기` 비활성 확인).
