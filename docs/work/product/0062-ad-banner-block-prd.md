# 0062 광고 블록과 크리에이터 배너 슬롯 요구 정리

- 단계: 티켓
- 역할: product
- 상태: 진행
- 종류: 제품 결정
- 우선순위: P1 (AI 제안)
- 작성일: 2026-10-09

## 목적

크리링 수익화를 위해 공개 랜딩에 광고 배너 영역을 둡니다. 무료 크리에이터의 랜딩에는 크리링 광고가 나가고, 유료 회원의 랜딩에서는 같은 자리가 크리에이터가 관리하는 배너 슬롯이 됩니다. 디자인·기술 설계로 넘기기 전에 사용자 결정을 PRD 요구로 옮기고, 유사 서비스 근거와 남은 결정 질문을 정리합니다.

조사 질문:

1. 리틀리 광고 블록은 누가 켜고, 수익은 어떻게 나누고 정산하는가?
2. 다른 링크 인 바이오 서비스는 유료 플랜과 광고를 어떻게 묶는가?
3. 외부 광고 네트워크를 붙일 때 정책상 막히는 화면은 무엇인가?

끝낼 조건: 사용자 결정을 PRD R20~R22로 옮기고, 수용 기준은 `[AI 제안]`, 답하지 못한 것은 미정 질문으로 남깁니다. 사용자가 답하면 디자인과 기술 설계 work item을 만듭니다.

### 사용자 결정(2026-10-09)

1. 수익화 수단은 공개 랜딩의 광고 배너 영역이다. 유료 회원의 랜딩에서는 같은 영역이 크리링 광고가 아니라 크리에이터가 꾸미고 관리하는 배너 슬롯이다.
2. 위치는 크리에이터가 끌어서 바꿀 수 있다. 범위는 링크 사이 어디든이다.
3. 리틀리 광고 블록과 같은 사업 모델이다. 광고 수익은 크리에이터와 나눈다.
4. 무료 랜딩의 광고 블록은 지울 수 없고 위치만 옮길 수 있다.
5. 배너 슬롯은 스와이프로 넘길 수 있는 형태다.
6. 광고는 운영자가 등록한 배너로 시작하고, 외부 광고 네트워크는 나중에 더한다.
7. 배너 슬롯(유료)은 지금은 결제 없이 운영자가 수동으로 부여한다.
