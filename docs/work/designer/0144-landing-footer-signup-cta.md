# 0144 공개 랜딩 하단 가입 유도 문구

- 단계: 티켓
- 역할: designer
- 상태: 완료
- 종류: 기능
- 우선순위: P1
- 작성일: 2026-10-10

## 목적

공개 랜딩 하단(`apps/web/src/app/(public)/p/[publicId]/page.tsx` `profile-footer`)에는 `크리링` 글자 링크와 개인정보 처리방침만 있습니다. Linktree는 공개 페이지가 다른 사람을 데려오는 구조를 성장의 첫 이유로 꼽았고, 리틀리는 무료 페이지 하단에 "1분만에 내 페이지 만들기 무료" 배지를 둡니다([조사](../../product/research/initial-user-acquisition.md#사례별-초기-확보-방식)). 실사용자 랜딩이 늘수록 사람 계정 없이도 방문자가 크리링으로 오는 채널입니다.

## 수용 기준

- [x] 공개 랜딩 하단에 "나도 크리링 만들기" 같은 가입 유도 문구 시안이 있고, 누르면 크리링 홈으로 갑니다. 유입 경로 기록(0087)이 생기면 랜딩에서 온 것을 구분할 수 있게 주소 규칙을 인계에 적습니다.
- [x] `design/system/DESIGN.md`의 공개 랜딩 장식 규칙(크리에이터가 주인공, 광고 블록 하나 예외)과 맞는지 판단하고, 규칙을 고친다면 같은 변경에서 고칩니다.
- [x] 배너 슬롯(R21)을 받은 유료 계정에서 이 문구를 둘지 정하고 근거를 남깁니다.
- [x] 390px·1280px 시안과 인계 문서가 있습니다.

## 범위

- 포함: 공개 랜딩 하단 문구 시안, 디자인 시스템 규칙 판단, 인계.
- 제외: 구현.

## 위험·복구

크리에이터 화면에 크리링 홍보가 늘면 크리에이터 반발이 생길 수 있습니다(PRD R20 위험과 같은 성격). 문구는 작고 한 줄로 둡니다.
