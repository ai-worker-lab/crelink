# 0064 광고 블록과 배너 슬롯 디자인

- 단계: 티켓
- 역할: designer
- 상위: 0063
- 상태: 준비
- 종류: 기능
- 우선순위: P2 (AI 제안)
- 작성일: 2026-10-09

## 목적

공개 랜딩에 크리링 광고 블록(R20)과 크리에이터 배너 슬롯(R21)을 그리고, 관리 화면과 운영자 화면에서 이를 다루는 모양을 정합니다. 지금 디자인 시스템은 "크리에이터 콘텐츠 영역(공개 랜딩)에 크리링 장식을 더하지 않는다"고 정해 두었으므로, 광고 표시·크기·위치 기준을 담아 이 규칙을 먼저 고칩니다.

## 수용 기준

- [ ] `design/system/DESIGN.md` `하지 말 것`의 공개 랜딩 장식 금지 줄을 광고 블록 기준으로 고친다. 기준은 `광고` 표시, 크기·비율, 링크 카드와 구별되는 방법, 크리링 표시 줄과의 관계다.
- [ ] 공개 랜딩 시안(390px·1280px)에 광고 블록이 링크 목록 맨 앞·사이·맨 뒤에 놓인 모양이 있다. 배너가 1장일 때와 여러 장일 때(스와이프, 위치 표시, 이전·다음 버튼, 키보드 초점)도 있다. 자동으로 넘어가지 않는다.
- [ ] 배너 슬롯(유료) 시안은 크리에이터 배너가 1장·여러 장일 때와 0장(숨김)일 때를 보여 준다. 광고 블록과 같은 자리·같은 틀이며 `광고` 표시가 없다.
- [ ] 관리 화면 `페이지 편집`(0056 미리보기 직접 편집 컨셉)에는 다음이 있다.
  - 광고 블록이 링크와 함께 끌어 정렬되는 항목으로 보이고, 삭제·숨기기 수단이 없다.
  - 배너 슬롯 편집 패널(휴대폰은 하단 시트)이 있다. 이미지·대체 문구·연결 URL, 추가·수정·삭제·정렬·숨기기, n장 한도 안내, 차단 표시를 다룬다.
- [ ] 운영자 화면에는 다음이 있다.
  - 크리링 배너 목록과 등록·수정·내리기 폼(이미지·대체 문구·연결 URL·게시 기간, 게시 중·예약·끝남 상태)
  - 크리에이터 상세(`/admin/creators/[userId]`)의 배너 슬롯 부여·회수
- [ ] `handoff.md`에 다음이 있다: 정보 구조, 상태(로딩·빈·오류 포함), 반응형, 접근성(스와이프 대체 수단, `aria`), 배너 이미지 비율·업로드 제한 제안, 지금 구현과 달라지는 점, 기술 검토 메모.
- [ ] 사용자가 시안을 승인한다.
- [ ] `pnpm design:check --require-lint`가 통과한다.
