# 0086 첫 크리링 광고 배너 이미지(크리에이터 가입 유도)

- 단계: 티켓
- 역할: designer
- 상태: 진행
- 종류: 운영
- 우선순위: P1 (AI 제안)
- 작성일: 2026-10-09

## 목적

광고 블록(PRD R20)은 게시 중인 크리링 배너가 없으면 공개 랜딩에서 보이지 않습니다(R20 ⑥). 그래서 첫 배너가 있어야 광고 구좌가 생기고 노출·클릭 기록도 쌓입니다. 2026-10-09 사용자 결정에 따라 첫 배너는 랜딩 방문자(크리에이터의 인스타그램 팔로워)를 새 크리에이터로 데려오는 가입 유도 배너로 씁니다. 지금 공개 랜딩에서 크리링으로 가는 길은 맨 아래 `profile-footer`의 작은 `크리링` 글자 링크뿐입니다.

## 수용 기준

- [ ] `design/first-ad-banner/assets/`에 운영자 광고 배너 화면에 바로 올릴 수 있는 배너 이미지가 있습니다. 문구 후보 2~3개이고, 모두 3:1 1200×400 PNG이며 4MB 이하입니다. 추천안은 하나입니다.
- [ ] 390px 공개 랜딩 폭에서 배너가 그려지는 크기로 봐도 문구가 읽힙니다. 크리링 이름이 보여 크리에이터 링크로 착각하지 않습니다. 이미지 안에 `광고` 표시를 따로 넣지 않습니다(블록 조작 줄 배지가 늘 붙음, R20 ③).
- [ ] `design/first-ad-banner/index.html`은 후보마다 배너 단독(1200×400)과 공개 랜딩 390px 안에 놓인 모습을 보여 줍니다.
- [ ] `design/first-ad-banner/handoff.md`에 다음을 적습니다. 운영자 등록 값(이미지 파일, 대체 문구 100자 이하, 연결 URL, 게시 시작), 추천 이유, 확인한 폭, `pnpm design:check --require-lint` 결과.
- [ ] 산출물에 색 리터럴이 없고 디자인 시스템 토큰만 씁니다.

## 범위

- 포함: 배너 이미지·시안·인계 문서.
- 제외: 운영 광고 배너 등록(모든 무료 랜딩에 공개되므로 사용자 승인 뒤 운영자가 등록), 가입 유입 경로 기록(0087), 광고 블록 UI 변경.

## 위험·복구

운영 등록 전까지 사용자에게 보이지 않습니다. 등록 뒤 문제가 있으면 운영자 화면 `내리기`로 바로 내립니다(R20 ④).
