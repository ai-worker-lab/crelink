# 0143 첫 사용 안내 디자인(실사용자 전환)

- 단계: 티켓
- 역할: designer
- 상태: 분류 대기
- 종류: 기능
- 우선순위: P1 (AI 제안)
- 작성일: 2026-10-10

## 목적

실사용자는 공개 랜딩에 보이는 외부 링크나 포트폴리오가 1개 이상 있는 계정입니다(PRD `목표`). 가입만 하고 비워 둔 계정은 세지 않습니다. 가입 직후 관리 화면에서 "링크 1개 추가 → 내 주소 복사 → 인스타그램 프로필에 붙이기"를 단계로 보여 주면 가입이 실사용자로 이어질 가능성이 높습니다. 기존 벤치마킹에서도 인링크가 3단계 안내와 "다음 한 걸음" 카드를 둡니다([벤치마킹](../../product/research/link-in-bio-benchmark.md#따라-할-것)).

## 수용 기준

- [ ] 빈 랜딩(링크·포트폴리오 0개) 관리 화면에 단계 안내가 보이고, 단계를 마치면 다음 단계로 넘어가며, 모두 마치면 사라지는 시안이 있습니다.
- [ ] 인스타그램 프로필 링크 넣는 방법(R1)을 짧게 안내하고, 크리링이 대신 등록하지 않는다는 전제를 지킵니다.
- [ ] 390px·1280px 시안과 인계 문서가 있습니다.

## 범위

- 포함: 관리 화면 첫 사용 안내 시안과 인계.
- 제외: 구현, 이메일·알림 발송(광고성 정보 수신 동의가 필요할 수 있음).
