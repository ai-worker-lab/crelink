# 0142 홈 소개 화면 보강 디자인

- 단계: 티켓
- 역할: designer
- 상태: 분류 대기
- 종류: 기능
- 우선순위: P1 (AI 제안)
- 작성일: 2026-10-10

## 목적

로그인 전 홈(`apps/web/src/app/(public)/page.tsx`)은 제목 한 줄, 설명 한 줄, `구글로 시작하기` 버튼뿐입니다. 처음 온 사람이 크리링 랜딩이 어떻게 생겼는지, 무엇이 무료인지 알 수 없습니다. 커뮤니티·검색·랜딩 하단에서 들어온 사람이 홈에서 가입을 정하므로, 홈이 모집 채널 모두의 도착지입니다([조사](../../product/research/initial-user-acquisition.md#결론)).

## 수용 기준

- [ ] 홈 시안에 예시 랜딩 모습, 사용 3단계(가입 → 링크 추가 → 인스타그램 프로필에 주소 넣기), 무료로 주는 것(단축 주소·주소 변경·외부 링크 5개), 가입 버튼이 있습니다.
- [ ] R24 이벤트 안내 자리(0089에서 만드는 홈 안내)와 겹치지 않고 함께 놓입니다.
- [ ] 로그인한 사람의 홈(지금의 `내 크리링 편집`)은 바뀌지 않거나 바뀌는 점을 인계에 적습니다.
- [ ] 390px·1280px 시안과 인계 문서(`design/<기능>/handoff.md`)가 있습니다.

## 범위

- 포함: 로그인 전 홈 시안과 인계.
- 제외: 구현(web 티켓으로 나눔), 예시 랜딩에 실제 크리에이터 데이터를 쓰는 것(허락 없이 쓰지 않음).
