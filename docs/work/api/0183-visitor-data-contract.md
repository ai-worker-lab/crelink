# 0183 방문자 행동 공유 계약

- 단계: 티켓

- 상위: 0182
- 상태: 완료
- 종류: 기능
- 우선순위: P1 (AI 제안)

## 목적

사용자의 기존 크리링 방문자 데이터 수집 확대와 후속 구현 지시를 수행한다.

## 수용 기준

- [x] 공개 응답의 optional telemetryToken·SNS/블록 식별자와 행동 요청 타입·경로를 공유한다.
- [x] UTM 6개 허용 목록과 리디렉트 보존에 필요한 공용 함수를 정의하고 의미 있는 검사를 추가한다.

## 범위

- 포함: [방문자 행동 설계](../../specs/crelink-visitor-data.md)의 해당 역할 범위.
- 제외: 운영 배포·운영 방문자 원본 조회·외부 광고/결제 연동·연락처 수집·새 통계 화면.

## 위험·복구

추가 migration은 기존 방문 데이터를 지우지 않는다. 공개 endpoint는 익명 분석용이며 로그인 권한을 부여하지 않는다. 문제 시 기존 리디렉트 흐름을 유지하고 새 Client tracker 전송을 중단할 수 있다. 운영 적용·롤백 실행은 이번 범위에 없다.
