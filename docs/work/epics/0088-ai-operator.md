# 0088 AI 운영자(전용 계정·실행 기록·30분 실행)

- 단계: 에픽
- 상태: 진행
- 종류: 기능
- 우선순위: P0
- 작성일: 2026-10-10

## 목적

2026-10-10 사용자 결정에 따라 크리링 운영을 AI에게 맡깁니다. 운영, 기능 기획, 설계, 개발, 배포까지 모든 권한을 AI 운영자에게 위임합니다(PRD R23). 1차 목표는 크리링 사이트를 보강하고 실사용자 100명을 모으는 것입니다(PRD `목표`). AI 운영자는 사람 세션이 아닌 전용 계정으로 일합니다. 30분마다 실행되며, 실행마다 기록을 남깁니다.

## 수용 기준

- [ ] AI 전용 크리링 계정이 있습니다. 운영자 권한을 갖고, 사람 Google 로그인 없이 API 토큰으로 운영자 API를 씁니다. 사람 계정과 구별되고, 토큰은 저장소에 들어가지 않습니다.
- [ ] 운영자 쓰기 행동(차단, 정지, 슬롯 부여, 배너 변경 등)은 누가(사람·AI), 언제, 무엇을, 어느 실행에서 했는지 기록에 남습니다.
- [ ] 30분 트리거가 AI 운영자를 실행합니다. 실행이 겹치지 않고, 실행마다 시작·끝·결과·한 일·다음 할 일이 운영 기록으로 남으며, 운영자 화면(휴대폰 폭 포함)에서 봅니다.
- [ ] 멈춤 스위치를 켜면 다음 실행이 아무것도 하지 않고 끝납니다.
- [ ] AI 운영자 헌장(목표·권한·지켜야 할 법·플랫폼 규칙·한 실행의 순서·개발과 배포 절차)이 저장소에 있고, 실행 프롬프트가 그것을 읽습니다.
- [ ] 저장소 정책(`AGENTS.md`, 저장소 공통 정책)이 AI 운영자 위임을 반영합니다(ADR).

## 범위

- 포함: AI 전용 계정과 API 토큰, 운영자 행동 기록, AI 실행 기록과 운영자 화면, 멈춤 스위치, 30분 트리거(Orca 자동화), AI 운영자 헌장과 실행 프롬프트, 실사용자 지표 조회, 정책·ADR 변경.
- 제외: 실사용자 모집 활동 자체(AI 운영자가 실행하면서 함), 슬롯 이벤트(0089).

## 위험·복구

- 운영 쓰기 권한을 사람 확인 없이 씁니다. 되돌림 수단은 행동 기록, 멈춤 스위치, 토큰 폐기, Orca 자동화 끄기입니다.
- 외부 모집 활동은 법(정보통신망법 제50조 광고성 정보 전송 동의 등)과 플랫폼 약관을 지켜야 합니다. 이 내용은 헌장의 지켜야 할 규칙으로 둡니다.

## 연결

- 설계·분해: [0091](../orchestrator/0091-ai-operator-design.md)

## 진행 기록

- 2026-10-10: 생성. 사용자 결정 원문은 다음과 같습니다. "모든 권한을 맡긴다. 운영부터 추가 기능 등 기획부터 개발까지 모두 ai 전용 계정을 만들자. 실행할때마다 기록을 남기자. 1차 목표는 크리링 사이트를 더 보강하고, 실 사용자 100명을 모집하기로 목표를 설정하라." 30분은 실행 트리거입니다. 같은 위임에 따라 이 에픽의 설계·디자인 승인과 머지는 AI(오케스트레이터 세션)가 하고 그 근거를 기록합니다.
