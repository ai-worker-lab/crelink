# 0063 랜딩 광고 블록과 크리에이터 배너 슬롯

- 단계: 에픽
- 상태: 완료
- 종류: 기능
- 우선순위: P2 (AI 제안)
- 작성일: 2026-10-09

## 목적

무료 크리에이터의 공개 랜딩에 크리링 광고 구좌(광고 블록)를 둡니다(PRD R20). 지금은 크리링 플랫폼 자신의 배너만 싣습니다. 운영자가 배너 슬롯을 부여한 계정에서는 같은 자리가 크리에이터가 관리하는 배너 슬롯이 됩니다(PRD R21).

## 수용 기준

PRD R20·R21 수용 기준(2026-10-09 채택)을 사용자 관점에서 끝까지 확인합니다. 시나리오와 확인 방법은 기술 설계(0065)의 검증 계획을 따릅니다.

- [x] 무료 랜딩: 광고 블록이 1개 있고 `광고` 표시가 보인다. 게시 중인 크리링 배너가 여러 개면 스와이프·이전/다음 버튼·키보드로 넘기고, 자동으로 넘어가지 않는다.
- [x] 크리에이터: 관리 화면에서 광고 블록을 링크 목록의 맨 앞·사이·맨 뒤로 끌어(키보드 포함) 옮기면 공개 랜딩에 그대로 보인다. 지우거나 숨길 수는 없다.
- [x] 운영자: 크리링 배너(이미지·대체 문구·연결 URL·게시 기간)를 등록·수정·내리기 할 수 있다. 연결 URL은 `http`·`https`만 받고 차단 목록 검사를 거친다.
- [x] 운영자가 계정에 배너 슬롯을 부여하면 그 계정 랜딩의 광고 블록이 같은 위치의 배너 슬롯이 된다. 크리에이터는 배너를 n장(설정값)까지 추가·수정·삭제·정렬·숨기기 할 수 있고, 상한에 닿으면 한도 안내가 보인다. 부여를 거두면 광고 블록으로 돌아가고 배너는 보관된다.
- [x] 게시 배너가 없거나 랜딩에 보이는 링크·포트폴리오가 없으면 광고 블록이 자리 없이 숨는다. 보이는 배너가 0장인 배너 슬롯도 숨는다.
- [x] 광고 배너 노출·클릭이 랜딩·배너별로 기록되고, 크리링 서비스 화면에서 연 랜딩의 보기·클릭은 세지 않는다. 기록은 크리링 내부에서만 본다.
- [x] 390px·1280px에서 가로 넘침이 없다.

## 범위

- 포함: 공개 랜딩 광고 블록·배너 슬롯, 관리 화면의 위치 정렬·배너 슬롯 편집, 운영자 화면의 크리링 배너 관리와 계정별 배너 슬롯 부여·회수, 노출·클릭 기록, `design/system/DESIGN.md` 공개 랜딩 장식 규칙 변경.
- 제외(사용자 결정 2026-10-09): 외부 광고주·외부 광고 네트워크·광고 판매, 크리에이터 광고 수익 배분과 수익 화면(R22 철회), 크리에이터의 광고 고르기(R20 ⑤, 외부 광고를 받을 때), 광고 블록 여러 개, 결제.

## 위험·복구

- 새 테이블·컬럼(배너, 슬롯 부여, 랜딩 항목 순서, 노출·클릭 기록)이 생깁니다. 되돌리는 방법은 기술 설계에서 정합니다.
- 공개 랜딩에 크리링 표시가 늘어나 디자인 시스템 규칙(`design/system/DESIGN.md`)을 바꿉니다. 노출 기록이 새 접근 기록 항목이면 개인정보 처리방침 고지를 함께 고칩니다(PRD R9 위험, 법률 검토 전).
