# 0175 외부 링크 50개 기본 제공과 광고 블록 켜고 끄기

- 단계: 에픽
- 상태: 진행
- 종류: 기능
- 우선순위: P1
- 작성일: 2026-10-12

## 목적

2026-10-12 사용자 결정 두 가지를 제품에 반영합니다.

1. 유료 링크 한도를 없앱니다. 모든 크리에이터가 처음부터 외부 링크를 50개(숨긴 링크 포함)까지 보이게 둘 수 있습니다. 보이는 한도를 늘리려고만 있던 운영자 추가 슬롯과 링크 슬롯 +5 이벤트는 지금 제거합니다.
2. 크리링 광고 블록(R20)에 스위치 두 개를 둡니다. 운영자 플랫폼 스위치와 크리에이터 계정 스위치이며 둘 다 기본 꺼짐입니다. 둘 다 켜지고 배너 슬롯이 없을 때만 공개 랜딩에 광고가 보입니다.

## 수용 기준

- [ ] 보이는 링크가 6개 이상인 크리에이터가 링크를 50개까지 추가하고, 51번째는 거절됩니다(숨긴 링크 포함).
- [ ] 운영자 추가 슬롯·링크 슬롯 이벤트의 화면·API·계약·안내 문구가 남아 있지 않습니다. DB의 `users.extra_link_slots`·`slot_events`·`slot_event_entries`는 지우지 않고 쓰지 않습니다.
- [ ] 플랫폼 스위치가 꺼져 있으면 공개 랜딩에 광고가 없고 편집 화면에 광고 블록 줄·스위치가 없습니다.
- [ ] 플랫폼 켬 + 크리에이터 끔이면 광고가 없고, 둘 다 켜면 광고가 보입니다. 꺼진 동안 광고 노출 수를 남기지 않습니다.
- [ ] 배너 슬롯이 부여된 크리에이터의 배너 슬롯은 스위치와 관계없이 그대로입니다.
- [ ] 운영자의 플랫폼 스위치 변경이 운영 기록에 남습니다.
- [ ] 약관·안내·PRD가 광고 노출은 선택이고 수익 배분 조건은 정해지지 않았다고 사실대로 말하며 수익을 약속하지 않습니다.

## 범위

- 포함: 공유 계약, migration 0007, API 한도·광고 블록 판정·스위치 경로, 운영자·편집 화면, 기능 제거, 안내·약관·PRD·설계 문서.
- 제외: 광고 수익 배분(정해지지 않음), 남은 DB 컬럼·테이블 삭제(0179에서 따로 결정).

## 위험·복구

배포하면 두 스위치가 기본 꺼짐이라 운영 랜딩의 광고가 사라집니다(의도한 결과). 운영자가 `/admin/ad-banners`에서 플랫폼 스위치를 켜도 크리에이터가 켜기 전에는 광고가 나오지 않습니다. 제거한 기능의 데이터는 그대로 두므로 코드 되돌림으로 복구할 수 있습니다.
