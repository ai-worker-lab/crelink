# 0241 공유관리 페이지

- 단계: 에픽
- 상태: 검증
- 종류: 기능
- 우선순위: P1
- 작성일: 2026-11-10

## 목적

한 페이지를 여러 사람이 각자 구글 계정으로 함께 관리하고 지표·통계를 함께 봅니다. 첫 사용처는 사용자 부부가 관리하는 아기 인스타그램 페이지입니다.

## 수용 기준

- [ ] 두 계정이 각자 로그인해 같은 페이지를 수정하면 공개 페이지에 반영되고, 두 계정 모두 같은 지표·통계를 봅니다.
- [ ] 초대받은 계정의 개인 페이지는 공유 페이지 편집으로 바뀌지 않습니다.

## 범위

- 포함: 초대, 공동 관리, 페이지 전환, 방명록 권한, 처리방침.
- 제외: 페이지 삭제, 소유권 이전, Expo 앱.
