# 0251 Instagram 댓글 자동 DM

- 단계: 에픽
- 상태: 진행
- 종류: 기능
- 우선순위: P2 (AI 제안)
- 작성일: 2026-11-11

## 목적

크리에이터가 게시물 댓글로 링크를 요청받을 때 일일이 DM을 보내는 수고를 없앱니다. 지정한 게시물에 키워드 댓글이 달리면 Meta 공식 API로 링크 DM 1건을 자동으로 보냅니다.

## 수용 기준

- [ ] 페이지 소유자가 프로페셔널 계정을 연결하고 게시물·키워드·메시지를 지정할 수 있습니다.
- [ ] 키워드 일치 댓글에 규칙당 사람별 1건만 발송되고, 웹훅 재전송과 동시 처리에도 중복 발송이 없습니다. 가짜 Graph API 시험으로 확인합니다.
- [ ] 위조된 웹훅은 거부되고 토큰은 암호화되어 응답·로그에 나타나지 않습니다.
- [ ] 공동 관리자와 AI 행위자는 연결·규칙을 바꿀 수 없습니다.
- [ ] 운영자 전체 스위치는 기본 꺼짐이며, 꺼진 상태로 배포해도 기존 기능에 영향이 없습니다.

## 범위

- 포함: 계정 연결, 규칙 설정, 웹훅 수신, 발송 worker, 발송 내역, 긴급 정지, 처리방침 항목.
- 제외: 일반 크리에이터 공개, Meta 비즈니스 인증과 앱 검수 제출, 전체 게시물 적용, 챗봇, 스토리·라이브, 유료화, Expo 앱.

## 위험·복구

- 2026-11-11 사용자 결정으로 사업자 없이 개발까지 진행합니다. Meta 문서상 앱에 역할이 없는 계정을 연결하려면 비즈니스 인증, 앱 검수, Advanced Access, Live가 모두 필요하므로 일반 공개는 이 에픽에서 하지 않습니다.
- 댓글 웹훅은 Advanced Access를 요구한다는 문구가 있어, 인증 없이는 실제 웹훅을 끝까지 확인하지 못할 수 있습니다. 이 경우 가짜 Graph API 시험까지만 검증한 것으로 기록합니다.
- 기능은 운영자 스위치로 꺼져 있으며 문제가 생기면 스위치를 끕니다. DB migration은 추가만 하고 되돌리지 않습니다.
- Meta 앱 생성, 시크릿 등록, 테스트 DM은 사용자 승인 뒤에 합니다.
