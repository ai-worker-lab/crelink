# 0046 랜딩 방명록 탭

- 단계: 에픽
- 상태: 진행
- 종류: 기능
- 우선순위: P1 (AI 제안)
- 작성일: 2026-10-08

## 목적

크리에이터 랜딩에 `방명록` 탭을 더해 방문자가 크리에이터에게 글을 남길 수 있게 합니다(PRD R19). 작성은 구글 로그인 회원만, 공개글은 누구나, 비밀글은 작성자와 대상 크리에이터만 봅니다. 크리에이터는 비방글을 숨기고(작성자에게는 그대로 보임) 방명록을 끌 수 있습니다.

## 수용 기준

[설계 검증 계획](../../specs/crelink-guestbook.md#검증-계획)의 E2E 시나리오로 확인합니다.

- [ ] 비회원은 공개글을 읽고, 작성 자리에서 로그인 안내를 보며, 로그인하면 같은 랜딩 방명록 탭으로 돌아온다. (읽기·안내·`returnTo`·콜백 뒤 복귀 구간은 확인, 실제 구글 로그인 성공 콜백을 거친 전체 흐름은 미확인)
- [x] 회원이 남긴 공개글은 누구에게나, 비밀글은 작성자와 대상 크리에이터에게만 보인다(화면과 API 응답 모두).
- [x] 크리에이터가 숨긴 글은 작성자에게 숨김 표시 없이 그대로, 크리에이터에게 숨김 표시로 보이고, 그 밖의 사람에게는 보이지 않는다.
- [x] 작성자는 자기 글을 지울 수 있다.
- [x] 작성자 이름·사진은 작성자 랜딩의 표시 이름·프로필 사진(없으면 '크리링 회원'·기본 프로필)이다.
- [x] 크리에이터가 관리 화면에서 방명록을 끄면 탭이 사라지고, 다시 켜면 이전 글이 보인다.
- [x] 390px·1280px에서 가로 넘침이 없다.

## 범위

- 포함: 공개 랜딩·관리 화면 보기 모드의 탭, 목록·작성·삭제·숨김, 관리 화면 끄기, 로그인 뒤 랜딩 복귀, 개인정보 처리방침 고지.
- 제외: 크리에이터 답글, 글 수정, 방문자 신고, 작성 빈도 제한, 운영자 방명록 화면, 새 알림, 디자이너 프로토타입(사용자 결정).

## 위험·복구

- 새 테이블·기본값 있는 새 컬럼만 더합니다(expand). 되돌리려면 코드를 되돌려 재배포하고, 운영 데이터가 생기기 전이면 다음 migration으로 테이블·컬럼을 지웁니다.
- 회원이 쓴 글(개인정보 포함 가능)을 보관·공개합니다. `/privacy` 고지를 같은 변경에 넣습니다. 법률 검토 전입니다(PRD 위험).
