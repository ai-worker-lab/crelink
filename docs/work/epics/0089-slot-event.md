# 0089 링크 슬롯 +5 이벤트(신청자 한정)

- 단계: 에픽
- 상태: 완료
- 종류: 기능
- 우선순위: P0
- 작성일: 2026-10-10

## 목적

2026-10-10 사용자 요청("신규 이벤트로 슬롯을 추가로 5개 제공하는 이벤트도 추가하라. 이벤트 신청한 사람에 한정한다")에 따라, 이벤트를 신청한 크리에이터에게 외부 링크 슬롯 5개를 더 줍니다(PRD R24). 실사용자 100명 모집 목표(PRD `목표`)를 위한 첫 가입·활성화 유인입니다.

## 수용 기준

- [x] 크리에이터가 관리 화면에서 이벤트를 신청하면, 그 계정의 보이는 외부 링크 한도가 5개 늘어납니다. 계정당 한 번이고, 신청하지 않은 계정은 그대로입니다.
- [x] 이벤트 보너스는 운영자가 수동 부여한 슬롯(R13)과 따로 셉니다. 운영자가 수동 슬롯을 바꿔도 보너스는 사라지지 않습니다.
- [x] 로그인 전 방문자도 홈에서 이벤트를 알 수 있고, 가입한 뒤 신청할 수 있습니다.
- [x] 이벤트 기간이 끝나면 새 신청은 받지 않고, 이미 받은 보너스는 유지됩니다.
- [x] 운영자(사람·AI)가 이벤트 기간과 신청자 목록·신청 수를 봅니다.
- [x] 390px·1280px에서 가로 넘침이 없습니다.

## 범위

- 포함: 이벤트 신청(관리 화면), 한도 계산, 홈 안내, 운영자 신청자 조회, 이벤트 기간 설정, 이용 안내 문서.
- 제외: 결제, 다른 종류의 이벤트 보상, 외부 홍보 활동(AI 운영자가 함).

## 위험·복구

새 테이블과 한도 계산 변경이 있습니다. 한도를 줄이는 방향의 되돌림은 이미 신청한 크리에이터의 링크를 숨기게 하므로, 보너스는 회수하지 않는 것을 기본으로 합니다.
