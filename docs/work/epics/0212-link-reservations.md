# 0212 링크별 사전 신청

- 단계: 에픽
- 상태: 진행
- 종류: 기능
- 우선순위: P2 (AI 제안)
- 작성일: 2026-11-10

## 목적

크리에이터가 링크(상품 링크)마다 방문자의 사전 신청을 받고, 들어온 신청을 관리 화면에서 보고 내려받을 수 있게 합니다. 수량·날짜·시간은 없는 사전 신청이며, 운영에서는 법률 검토 여부 결정과 처리방침 반영 전까지 꺼 둡니다.

## 수용 기준

- [ ] 크리에이터가 링크마다 끔·받기·마감과 받을 방식을 고르고, 공개 랜딩에서 방문자가 로그인 없이 신청합니다(R29).
- [ ] 크리에이터가 본인 링크의 신청만 목록·CSV로 보고, 건별·링크별로 지웁니다. 90일 뒤 자동 삭제됩니다(R30).
- [ ] `RESERVATIONS_ENABLED`가 없는 환경에서는 새 경로가 모두 404이고 공개 응답에 필드가 없습니다(R31).
- [ ] [설계](../../specs/crelink-reservations.md) 7절의 QA 시나리오를 브라우저와 API로 확인합니다.

## 범위

- 포함: 1단계 사전 신청(이메일·휴대폰). API는 0213, 웹·QA·통합·출시는 설계의 0219 이후 번호.
- 제외: 회원 방식(R32, 2단계), 수량·날짜·시간, 상품 모델·재고·결제, 메일·SMS 발송, 이름·메모 수집, 해외 번호, 운영자 열람, 신청 지표, 앱.

## 위험·복구

migration은 추가만 합니다. 운영 플래그를 켜지 않으면 수집이 일어나지 않습니다. 켜는 일은 처리방침 반영과 사용자 승인 뒤의 별도 작업입니다.
