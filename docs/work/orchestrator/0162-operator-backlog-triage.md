# 0162 AI 운영자 백로그 상태 정리와 다음 무비용 활성화 작업

- 단계: 티켓
- 역할: orchestrator
- 상태: 준비
- 종류: 운영
- 우선순위: P1
- 작성일: 2026-10-11

## 목적

실사용자 0/100 상태에서 `work:next`의 착수 가능 목록만 보고 무변경으로 종료하지 않도록, 전체 미완료 백로그의 제외 사유를 판정하고 다음 비용 없는 활성화 작업을 연결합니다. `분류 대기`·`진행`·`검증` 상태와 브랜치·PR·Deploy 증거를 함께 읽어 운영자가 계속 다음 행동을 선택하게 합니다.

## 수용 기준

- [ ] `node scripts/work.mjs --next --all --json`의 `eligible: false` 항목을 상태·사유별로 분류합니다.
- [ ] `진행`·`검증` 항목 중 브랜치·PR·Deploy가 끊긴 항목의 다음 행동을 work item 진행 기록에 남깁니다.
- [ ] 사람 결정·비용·외부 계정이 필요한 항목은 상태를 바꾸지 않고 `사람 결정 필요`로 기록합니다.
- [ ] 비용·외부 서비스·사람 계정 변경 없이 다음 활성화 작업 하나를 `준비` 또는 `진행` 상태로 연결합니다.
- [ ] 실행 기록에 지표, 선택 근거, 실제 변경, 다음 작업과 work item/PR/Deploy 연결을 남깁니다.

## 범위

- 포함: 저장소 work item 상태·진행 기록 정리, 무비용 작업 선택, AI 운영자 실행 계약 보강.
- 제외: 결제·광고·외부 홍보·사람 계정·유료 도구·운영 DB 직접 쓰기.

## 위험·복구

work item 상태 변경은 저장소 커밋으로 되돌립니다. 사람 승인 항목은 변경하지 않습니다. 비용·개인정보·외부 계정 작업은 사람 승인 전 금지합니다.
