# 0164 공개 랜딩→첫 공개 링크 활성화 실험

- 단계: 티켓
- 역할: orchestrator
- 상태: 검증
- 종류: 기능
- 우선순위: P1 (AI 제안)
- 작성일: 2026-10-11

## 목적

실사용자 0/100 상태에서 가입 수가 아니라 공개 랜딩을 실제로 채운 크리에이터를 늘립니다. 공개 랜딩 방문자가 가입 뒤 첫 공개 링크를 만들도록 가입 유도 문구와 기존 첫 사용 안내의 연결을 더 구체적으로 만들어, 외부 계정·비용·개인정보 수집 없이 가역적으로 검증합니다.

## 수용 기준

- [x] 공개 랜딩의 가입 유도 문구가 결과 행동(첫 링크 만들기)을 설명하고, 기존 가입·로그인 흐름과 첫 사용 안내로 이어집니다.
- [ ] 실험 전 7일과 배포 후 7일에 `0161` 활성화 지표의 지표 대상 가입자 수·첫 공개 링크 수·전환율을 같은 정의로 기록합니다.
- [ ] 지표 대상 가입자가 5명 미만이면 성공·실패 결론을 내리지 않고 표본 부족으로 기록합니다.
- [x] 390px·1280px에서 가로 넘침·콘솔 오류·접근성 회귀가 없고 기존 오류 랜딩의 바닥글 동작을 유지합니다.
- [x] 외부 계정·외부 게시·광고비·새 식별자·운영 DB 직접 쓰기가 없으며, 문구는 PR revert로 되돌릴 수 있습니다.

## 범위

- 포함: 공개 랜딩 가입 CTA 문구·연결, 기존 첫 사용 안내와의 행동 연결, 관련 E2E·웹 변경 기록, 0161 기준선 비교 기록.
- 제외: 검색엔진 소유 확인·sitemap 제출(0148), 외부 모집·게시(H1~H5·0153), 가입 유입을 개인과 연결하는 attribution(0087), 개인정보 처리방침·법률 문구 변경.

## 위험·복구

새 개인정보나 운영 상태를 만들지 않습니다. CTA가 오해를 주거나 전환·접근성·화면을 악화하면 PR을 revert하고 기존 문구로 복구합니다. 표본이 부족한데 결론을 내리지 않습니다.
