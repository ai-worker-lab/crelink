# 0169 첫 크리링 완성 챌린지 기획과 자사 캠페인

- 단계: 티켓

- 우선순위: P1

## 목적

**첫 크리링 완성 챌린지**를 자사 공개 문서 경로에 구현합니다. “목적 고르기→직접 대표 링크 등록→본인의 프로필 공유 준비”의 자발적 3단계로 첫 가치를 경험하게 하는 안내입니다. 참여에 새 금전/경품 보상이나 외부 게시 의무를 걸지 않습니다. 기존 신청자 한정 슬롯 +5 이벤트(R24)는 실제 공개 API 상태를 확인한 뒤 별도 선택 혜택으로 소개하고 조건을 변경하지 않습니다. `0168` 편집기와 `0164` CTA는 수정하지 않으며 공통 결과 지표의 중복 영향은 기록합니다.

## 팀별 과제

- Events/Lifecycle: 현행 혜택·조건·자발적 신청·첫 링크 연결 시나리오.
- Growth/Marketing: 자사/외부 채널용 사실 기반 안내 소재. 무료 외부 게시와 비용 없는 보상 조건은 PM이 준수/접근·제품 계약으로 판단하며 지출/결제만 사람 승인으로 분리합니다.
- Product/Web: 신청에서 실제 링크 작성으로 이어지는 UX와 대안 비교.
- API/Data: 기존 한 번 신청·보너스 합산 계약과 측정 가능 지표 검토. 집계 공백을 사실로 보고.
- SRE/Security/QA: 출시/되돌림·보상 오표시·중복 신청·개인정보·권한 검토.

전담 `crelink-pm`이 팀별 조사·보고·실제 구현/홍보를 통합합니다. 무료 회사 계정·홍보 자체를 승인 대기로 두지 않습니다. 이 과제의 현재 범위를 넘는 새 추첨·개인정보 수집은 구현에 몰래 포함하지 않으며 지출/결제/비용 약정은 사전 사람 승인, 법·약관·동의·권한은 실행 조건으로 구분합니다.

## 게시 기간과 중복 영향

- 대상: 아직 페이지가 비어 있거나 첫 링크를 무엇으로 할지 정하지 못한 크리에이터. 기존 작성자도 목적/공유 준비만 점검할 수 있습니다. 챌린지 등록·참여 인원 개념은 만들지 않습니다.
- 실제 자사 소재: 새 안내의 제목·도입·3단계·자율/무보상 고지·현재 슬롯 상태·관리 링크, 문서 목록 설명 및 문서 메뉴. 이 출시 전 checkpoint에서는 새 캠페인 안내의 추가 외부 게시/DM/이메일을 수행하지 않았습니다. 기존 G1/G2 홍보와 출시 후 추가 공개는 0153 및 이번 운영 실행 기록·연결 PR 출시 댓글의 실제 결과로 구분합니다.
- 실제 게시 시각 원본: 출시 전에는 값을 만들지 않습니다. 승인한 상시 게시 기간의 T0는 성공한 Deploy의 운영 주소 검사와 실제 공개 화면 확인으로 정하고 `ba81feb2-50e5-49d5-b92f-858e0c9ff86a` 운영 실행 기록·연결 PR의 출시 댓글에서 확인합니다. T0+7일은 첫 리뷰이지 참가 마감/자동 종료가 아닙니다. 철회는 새 가이드/문서 등록만 revert하고 사용자 링크·기존 신청/보너스는 보존합니다.
