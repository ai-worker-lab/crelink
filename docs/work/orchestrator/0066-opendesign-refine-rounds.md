# 0066 위임·반복 작업 기준(OpenDesign 다듬기 회차 회고)

- 단계: 티켓
- 역할: orchestrator
- 상태: 검증
- 종류: 유지보수
- 우선순위: P2 (AI 제안)
- 작성일: 2026-10-09

## 목적

0064 광고 블록 디자인은 생성 1회와 다듬기 11회로 1시간 40분이 걸렸습니다. 회차별 내용(`docs/work/designer/0064-ad-banner-block-design.md` 진행 기록, 에이전트 기록)을 보면 줄일 수 있었던 회차가 있습니다. 같은 문제는 디자인뿐 아니라 subagent에 맡기는 반복 작업 전반에서 생길 수 있습니다.

- 2회차: 지금 웹 CSS·마크업을 참고 파일로 넣었습니다. 처음부터 넣었다면 운영자 화면 모양 차이를 생성 단계에서 막을 수 있었습니다.
- 7회차: 앞 회차들이 덧붙인 같은 이름의 렌더 함수가 여러 번 정의돼 있어(파일 207KB) 그 중복을 정리한 회차입니다. 다듬기 방식이 스스로 만든 비용입니다.
- 8~11회차: 박힌 문구 1개, 시트 버튼 줄, `od lint` P0 1개, 대화상자 머리처럼 작은 수정을 한 run에 하나씩 돌렸습니다. 이 중 lint P0은 `od lint`를 회차마다 돌렸다면 일찍 잡혔습니다.
- 5·6회차는 각각 "마무리"·"마지막"이라고 적었지만 이후에도 다섯 회차가 더 이어졌습니다.

## 수용 기준

- [x] 루트 `AGENTS.md`에 `위임과 반복 작업` 절을 두고 다음을 적는다.
  - 기준 자료를 처음에 모두 넘김(승인 산출물, 지금 코드·CSS·마크업, 요구 원문)
  - 회차마다 기계 검사
  - 확인한 결함은 한 회차에 모아 고침
  - 5회차나 30분을 넘기면 맡긴 쪽에 보고하고, 맡긴 쪽도 진행을 확인함
  - "마지막" 뒤 회차를 더하면 이유를 남김
  - 절차 단계를 미루지 않음
- [ ] 다음 위임 반복 작업(디자인 티켓 등) 하나에서 적용하고, 회차 수와 걸린 시간을 기록한다.
