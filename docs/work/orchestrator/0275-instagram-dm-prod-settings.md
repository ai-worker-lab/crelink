# 0275 Instagram DM 운영 연동 설정 배포

- 단계: 티켓
- 역할: orchestrator
- 상태: 검증
- 종류: 운영
- 우선순위: P2 (AI 제안)
- 작성일: 2026-11-11

## 목적

사용자가 등록한 Meta 앱·Instagram 보안 설정을 기존 SOPS 배포 경로로 적용해 운영자에게 DM 메뉴를 제공한다.

## 수용 기준

- [x] API 설정 파서로 필수 8개 항목·키 형식·키 분리를 검증하고 비밀값은 출력하지 않는다.
- [x] SOPS 암호문에만 비밀값을 보관하고 선택한 로그인 구성 ID와 일치 여부만 확인한다.
- [ ] 로컬 CI·양측 검수 통과 후 PR 병합, Deploy 성공과 운영 설정·메뉴 확인.

## 범위

- 포함: 사용자 변경 `infra/prod/secrets/home-server.sops.env`, 변경 기록, 본 티켓, 인프라 계약.
- 제외: 앱 코드·Meta 앱 설정 변경·OAuth 계정 연결·규칙 생성·DM 시험 발송.

## 위험·복구

필수 설정이 모두 있으면 Instagram worker가 시작한다. 사용자가 공개 범위를 운영자만으로 설정했다고 보고했다. 기존 연결·규칙 여부를 배포 전 읽기 전용으로 확인한다. 기존 대기 발송이 있으면 활성화로 발송될 수 있으므로 배포하지 않고 영향부터 확인한다. 이번 작업에서는 외부 DM을 시험 발송하지 않는다. 설정 오류로 새 색 기동이 실패하면 기존 Blue/Green 배포가 기존 색을 유지한다. 롤백은 기존 배포 런북을 따르고 DB는 되돌리지 않는다.
