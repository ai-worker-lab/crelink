# 0208 운영자 age 키 교체

- 단계: 티켓
- 역할: orchestrator
- 상태: 완료
- 종류: 운영
- 우선순위: P1
- 작성일: 2026-11-09

## 목적

운영자 Mac 초기화로 옛 운영자 age 키를 잃었고 비밀번호 관리자 사본도 없습니다. 지금은 서버 키로만 운영 암호문을 풀 수 있어 서버 키까지 잃으면 복구할 수 없습니다. 새 운영자 키를 만들어 수신자를 바꿉니다.

## 수용 기준

- [x] 새 운영자 키가 M4 키체인 `crelink-sops-age`/`operator`에 있고 개인키가 화면·파일·기록에 남지 않습니다.
- [x] `.sops.yaml`의 operator 수신자가 새 공개키이고 옛 수신자가 없습니다.
- [x] `infra/prod/secrets/home-server.sops.env`의 복호화 평문이 교체 전후 같습니다(해시 비교, 값은 출력하지 않음).
- [x] 새 운영자 키와 서버 키 양쪽으로 복호화됩니다.
- [x] 머지 뒤 Deploy가 성공합니다.

## 범위

- 포함: 수신자 교체, 키를 잃었을 때의 런북 절차.
- 제외: 앱 비밀값 자체의 회전. 옛 키는 유출이 아니라 초기화로 사라졌습니다.

## 위험·복구

`updatekeys`는 데이터 키를 다시 감쌀 뿐 값을 바꾸지 않습니다. Deploy가 실패하면 런북 7로 롤백합니다. 이전 릴리스의 암호문은 서버 키로 계속 풀립니다.

## 연결

- 런북: [4-5 회전](../../../infra/docs/prod-runbook.md#4-5-회전)
