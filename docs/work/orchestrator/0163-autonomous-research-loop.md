# 0163 AI 운영자 능동 연구·실험 루프

- 단계: 티켓
- 역할: orchestrator
- 상태: 검증
- 종류: 운영
- 우선순위: P1
- 작성일: 2026-10-11

## 목적

크리링 AI 운영자가 장애·실패 배포·열린 PR이 없다는 이유로 운영을 멈추지 않고, 공개 자료·현재 지표·사용자 피드백을 조사해 실사용자 100명 목표의 다음 무비용 실험을 계속 연결합니다. 조사 결과는 사실과 추론을 분리하고, 외부 계정·홍보·비용·법률 위험은 사람 승인으로 분리합니다.

## 운영 방법

1. PostHog의 활성화 지표·퍼널 원칙과 Google Search Central의 검색 기본기를 포함한 공식 자료를 우선 확인합니다.
2. 크리링의 최신 `context` 지표와 기존 `docs/product/research/` 자료를 함께 읽어 병목을 한 문장으로 정의합니다.
3. `가설 → 측정 지표 → 비용 없는 가역적 실험 → 멈춤 조건`을 기록합니다.
4. 저장소 문서·코드·로컬 검증·PR 중 안전한 다음 행동 하나를 같은 실행에서 착수합니다. 외부 게시·사람 계정·유료 도구가 필요한 행동은 `사람 결정 필요`로만 남깁니다.

## 수용 기준

- [x] PostHog 활성화 지표 글·퍼널 문서와 Google SEO Starter Guide의 URL 및 확인일을 기록하고, 공개 자료의 사실과 크리링에 대한 추론을 구분합니다.
- [x] 실사용자 0/100, 크리에이터 4명(지표 제외 0명), 7일 방문 3건·외부 링크 클릭 0건을 기준선으로 삼아 가장 큰 병목을 `외부 유입 부족 + 지표 대상 가입자 0명으로 활성화 코호트 비교 불가`로 정했습니다.
- [x] 비용·외부 계정·운영 데이터 파기 없이 실행 가능한 가역적 실험 work item `0164`를 연결합니다.
- [x] 실험 전후 비교 방법과 중단 조건을 아래 진행 기록 및 `0164`에 남깁니다.
- [x] 비용·외부 홍보·사람 계정·법률/개인정보 위험이 필요한 검색엔진 등록·모집 채널 실행은 상태를 바꾸지 않고 사람 승인 항목으로 분리합니다.

## 범위

- 포함: 공개 운영 방법 조사, 활성화 가설, 지표 설계, 저장소 문서·코드·로컬 검증·PR 연결.
- 제외: 결제·광고 집행·외부 홍보·사람 계정 로그인/제출·스크래핑·대량 DM·운영 DB 직접 쓰기.

## 진행 기록

- 2026-10-11: 생성. 0/100 상태에서 `eligible: false`만 보고 무변경으로 끝내지 않도록, 매 실행의 연구·가설·무비용 실험 연결을 운영 계약에 추가했습니다. 외부 채널·비용·사람 계정은 계속 승인 게이트에 둡니다.
- 2026-10-11: `context` 기준선은 실사용자 0/100, 크리에이터 4명(지표 제외 0명), 가입 7일 4명, 방문 7일 3건, 링크 클릭 7일 0건입니다. 지표 대상 가입자가 0명이라 가입 후 첫 공개 링크 활성화 코호트를 아직 비교할 수 없고, 다음 실험의 첫 관찰 지점으로 삼습니다.
- 2026-10-11: PostHog는 활성화를 가입 자체가 아니라 이후 유지와 상관된 행동 묶음으로 찾고, 후보 행동을 여러 횟수·기간으로 비교하라고 설명합니다([활성화 지표](https://posthog.com/product-engineers/activation-metrics), 2024-11-28 확인). 퍼널 문서는 가장 단순한 순서로 시작하고 단계별 이탈·전환·전환 시간을 비교하라고 합니다([퍼널](https://posthog.com/docs/product-analytics/funnels), 2026-10-11 확인). Google은 유용하고 독창적인 사람 중심 콘텐츠, 설명적인 제목·URL·내부 링크를 권장하지만 검색 반영은 수 시간에서 수개월 걸릴 수 있고 sitemap 제출은 필수가 아니라고 설명합니다([SEO Starter Guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide), 2026-10-11 확인).
- 2026-10-11: (추론) 현재 가장 값싼 가역 실험은 공개 랜딩의 가입 유도에서 관리 화면의 첫 공개 링크 생성까지 한 단계로 연결하고, 기존 `0161` 활성화 지표로 7일 코호트를 비교하는 것입니다. 외부 검색엔진 계정 제출과 H1~H5 모집은 사람 계정·외부 공개가 필요하므로 이번 실행에서 하지 않습니다.
- 2026-10-11: `0164`를 `준비`로 등록했습니다. 가설은 “공개 랜딩의 구체적인 첫 링크 CTA와 기존 첫 사용 안내가 가입자의 첫 공개 링크 생성을 늘린다”입니다. 실험 전 7일 기준선과 배포 후 7일을 비교하고, 지표 대상 가입자 5명 미만이면 결론을 내리지 않습니다. 개인정보·법률 문구 변경이나 외부 게시가 필요해지면 즉시 중단합니다.
