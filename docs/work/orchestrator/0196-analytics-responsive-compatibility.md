## 목적

디자인 기준에서 요구하는 기기 대응을 실제 지표·통계의 공통 필터·표·차트와 회귀 검증에 반영한다. 현재 문서 기준 추가와 제품 수정 완료를 구분하기 위한 후속 결함 항목이다.

## 수용 기준

- [ ] 보고된 iPhone의 날짜 입력 겹침·카드 경계 넘침과 두 페이지의 일별 날짜 분절을 해소한다.
- [x] 긴 표의 최근 자료·다음 구간 접근과 모바일 핵심 숫자 우선 노출을 보완한다.
- [x] 차트 레이블 실제 렌더 크기와 빠른 기간의 터치 영역·선택 상태를 기준에 맞춘다.
- [x] 변경한 페이지를 다중 엔진·모바일 조건에서 검증하고 전후 스크린샷을 비교한다. 보고된 실물 결함의 미확인 범위를 남긴다.
- [ ] 검증한 변경만 PR·CI·main 병합 후 GitHub Actions로 운영에 배포하고 이미지·서버 전환·운영 주소 검사·배포 태그를 확인한다.
- [ ] 보고된 운영 분석 화면에서 변경된 UI·날짜 조회·표를 확인하고 실물 재확인과 구분해 기록한다.

## 범위

- 포함: apps/web의 공통 지표·통계 UI, 필요한 tests 회귀, 관련 인계·검증 기록.
- 제외: 지표 수집·집계 정의 변경, 인증 변경, 새 프레임워크·유료 실물 테스트 서비스의 자동 도입.

## 위험·복구

조회 범위·null/0 의미·기간 조건을 유지한다. native 입력을 교체한다면 키보드·접근성·locale 동작을 확인한다. 구현·배포 범위는 착수 시 정하며 이 항목의 등록은 실행·배포 승인으로 대신하지 않는다.
