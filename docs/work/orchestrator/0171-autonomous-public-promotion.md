# 0171 무료 외부 홍보 자율 실행 권한 전환

- 단계: 티켓

- 종류: 운영
- 우선순위: P1

## 목적

사용자는 "외부 홍보도 자체적으로 하라. 지출, 결제만 사람 승인 필수로 한다"고 명시했습니다. 무료 홍보의 사람 승인 대기를 제거하고 Crelink PM이 채널 조사·회사 계정 접근·문안·실제 게시/동의된 연락·결과 확인을 담당하도록 전환합니다. 지출·결제·유료 구독/크레딧·비용 발생 약정만 사전 사람 승인 대상으로 둡니다.

## 범위

무료 공개 소개·모집·회사 채널 운영은 PM이 판단합니다. 직접 메시지는 수신동의와 채널 규칙을 충족한 대상만, 플랫폼 금지 자동화·대량 발송·사칭은 하지 않습니다. 기존 허용 회사 계정과 플랫폼이 허용하는 무료 회사 계정 구성을 이용하고 인증·OTP·실제 사용자 확인이 막히면 정확한 접근 선행 조건을 기록합니다. 접근 불가를 사람이 홍보를 승인하지 않았다는 이유로 바꾸지 않습니다. 개인계정 임의 사용·인증 우회·운영 개인정보 전용은 금지합니다.

실제 게시/발송 결과는 URL·시각·채널/규칙·제출/공개/거절/접근 불가·철회 경로와 관측일을 구분합니다. 문안 준비·설정 변경을 게시나 유입 성과로 기록하지 않습니다. 새로운 유료 계정/광고/구독/보상 지출은 사람이 승인하기 전 실행하지 않습니다.
