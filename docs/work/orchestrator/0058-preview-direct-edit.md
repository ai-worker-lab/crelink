# 0058 페이지 편집 미리보기 직접 편집·프로필 메뉴 구현

- 단계: 티켓
- 역할: orchestrator
- 선행: 0056, 0057
- 상태: 검증
- 종류: 기능
- 우선순위: P2 (AI 제안)
- 작성일: 2026-10-08

## 목적

승인된 시안(0056, `design/preview-direct-edit/`)대로 관리 화면의 `페이지 편집`을 미리보기 직접 편집으로 바꾸고, 프로필·SNS 채널을 별도 `프로필` 메뉴로 옮깁니다. 지금(0053)은 고정 카드 5개를 패널에 쌓고 옆에 미리보기를 두어, 고칠 곳을 카드 목록에서 찾아야 합니다.

## 수용 기준

- [x] 1024px 이상: 왼쪽 메뉴(페이지 편집·프로필·방명록·주소 설정) · 가운데 무대(주소 막대 + 휴대폰 미리보기) · 오른쪽 편집 패널. `내 페이지` 머리 카드와 머리글의 `공개 페이지 열기`는 없고 주소 막대(단축 주소·복사·주소 변경·공개 페이지 열기·`저장하지 않은 변경 포함`)가 대신한다.
- [x] 페이지 편집: 미리보기의 외부 링크 구역·링크 하나·포트폴리오 구역·항목 하나·`+ 링크 추가`·`+ 포트폴리오 추가`·방명록·프로필 머리/SNS를 고르면 패널이 그 내용(목록·폼·스위치·프로필 안내)으로 바뀐다. 처음 패널은 구역 목록, `← 전체`로 돌아가고, 고르면 초점이 패널 제목으로, 돌아오면 고른 대상으로 간다.
- [x] 초안은 항목별로 남아 다른 항목을 고르거나 `← 전체`·메뉴 이동 뒤에도 미리보기에 그대로 그려지고 `저장 안 함`이 붙는다. `취소`·저장 성공만 지운다. 숨긴·차단 링크는 미리보기에 없고 외부 링크 패널 목록에서만 다룬다.
- [x] `프로필` 메뉴(`/me/landings/{publicId}/profile`): 프로필·SNS 채널 폼, 미리보기는 맨 위에서 프로필 머리·SNS 줄만 강조.
- [x] 1023px 이하: 가로 탭, sticky 줄(주소·복사·공개 페이지 열기, `편집 | 미리보기`), 페이지 편집은 편집 칩이 있는 전체 폭 랜딩에서 누르면 하단 시트(Esc·닫기 뒤 누른 대상으로 초점), 다른 메뉴는 폼이 기본. 떠 있는 `미리보기` 버튼은 없다. 320px 가로 넘침 없음.
- [x] PRD R18, 기술 설계, E2E, `/docs/guide`, 웹 README·변경 기록을 새 화면에 맞춘다. 새 API·공유 계약 변경 없음.
- [x] `pnpm verify`·`pnpm smoke`·`pnpm e2e` 통과.

## 범위

- 포함: `apps/web`(관리 화면 틀·페이지 편집·프로필 메뉴·미리보기 고르기·초안), PRD R18, `docs/specs/crelink-mvp.md`·`docs/specs/crelink-guestbook.md`의 관리 화면 서술, `tests/e2e/`.
