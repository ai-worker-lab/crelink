# 0198 생성자가 선택하는 링크 표시 방식

- 단계: 티켓
- 역할: orchestrator
- 상태: 검증
- 종류: 기능
- 우선순위: P1
- 작성일: 2026-11-06

## 목적

링크 생성자가 리스트/카드형 그리드를 골라 방문자에게 보여 준다.

## 수용 기준

- [x] 생성자의 외부 링크 설정에서 두 표시 방식을 선택·저장하며 미리보기와 공개 페이지가 일치한다.
- [x] 기존 랜딩은 리스트를 유지하고 다른 사람·비로그인은 변경할 수 없다.
- [x] 그리드는320px 이상2열·상품 사진 원형 유지·이미지 없는 항목 대체 표시·긴 제목 줄바꿈·배너 전체 열로 동작한다.
- [x] 저장 실패 복구·새로 고침·순서·숨김/차단·클릭 주소·키보드·모바일/데스크톱을 검증한다.

## 범위

- 포함: 기존 PATCH 랜딩 계약, 표시 방식 필드1개, 기존 Landing 컴포넌트·토큰 재사용.
- 제외: 방문자 전환 버튼·열 수 옵션·테마/레이아웃 빌더·관리 정렬 목록의 그리드화.

## 위험·복구

추가 전용 migration0011, 기본 list·CHECK(list/grid), lock_timeout5s. 이전 API는 새 컬럼을 무시하므로 rollback 때 컬럼을 지우지 않는다. 운영 반영은 GitHub Actions만 사용한다.
