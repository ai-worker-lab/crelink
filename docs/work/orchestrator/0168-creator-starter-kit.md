# 0168 협업 문의용 크리에이터 시작 키트

- 단계: 티켓
- 역할: orchestrator
- 상태: 검증
- 종류: 기능
- 우선순위: P1
- 작성일: 2026-10-11

## 목적

협업 문의용 프로필을 만들려는 크리에이터에게 완성 예시·실제 작성 방법·링크 목적별 제목 프리셋을 제공해 처음부터 무엇을 써야 하는지 정하게 합니다. 공개 가이드는 신규 유입을 위한 마케팅 자산으로도 사용합니다. 사용자 요청과 운영자 위임에 따른 AI 승인입니다. 효과는 아직 검증되지 않았습니다.

## 수용 기준

- [x] 착수 시 현재 화면과 기존 가이드를 읽고 중복 기능을 확인한 뒤, 제품 요구·기술 설계·디자인 인계를 기존 절차로 확정합니다. 새 공개 인증 경로 없이 기존 `/docs`와 관리 화면을 재사용합니다.
- [x] 공개 가이드는 협업 문의용 링크 구성 예시, 무료 범위, 직접 작성 단계, 가입 동선을 제공합니다. 일반 인스타그램 가이드의 복제나 경쟁사 콘텐츠 복사는 하지 않습니다.
- [x] 완성 예시는 가상의 예시라고 명시하며 실제 고객·성과·후기인 것처럼 보이지 않습니다. 운영 계정/랜딩을 만들거나 다른 크리에이터 콘텐츠를 무단 사용하지 않습니다.
- [x] 관리 화면에서 협업 문의/대표 작업/주요 채널 목적을 고르면 해당 목적의 링크 제목을 제안합니다. URL은 사용자가 직접 입력합니다. 선택만으로 저장·공개하거나 기존 링크/프로필을 덮어쓰지 않습니다.
- [x] 프리셋 없이 기존 편집도 그대로 가능하며, 기존 URL 안전 검사·링크 한도·권한·저장 오류 처리 계약을 재사용합니다. 예시 링크는 사용자에게 자동 저장하지 않습니다.
- [x] 문서 목록/기존 안내에서 공개 가이드를 찾을 수 있고 기존 Google 가입·관리 화면 흐름과 연결됩니다. `0164` CTA 측정 대상 문구는 별도 근거 없이 재변경하지 않습니다.
- [x] localhost에서 390px·1280px 실제 가이드·예시·목적 선택·사용자 URL 저장과 실패/한도 상태를 확인합니다. 실제 링크 저장만 기존 활성화 집계에 반영되고 예시 열람은 성과에 포함되지 않습니다.
- [ ] CI→guard→main→Deploy→운영 주소 검사 근거를 기록하고 배포 시각·7일 뒤 점검일·되돌림 방법을 남깁니다.

## 팀별 소유 과제

- Product: 협업 문의 사용자 시나리오·제목 프리셋과 첫 링크 완료 기준 확정.
- Research: 아래 조사에서 사실·가설·보류 대안과 추가 사용자 근거 검토.
- Growth/Marketing: 실제 기능 기반 가이드·타깃 문안·내부 링크. 무료 외부 게시/동의된 초대는 `0153`의 현행 규칙·접근 조건을 확인하고 PM이 자율 실행하며 지출/결제만 사람 승인을 받습니다.
- Web/UX: 가상 완성 예시와 목적 선택/직접 입력 UX·모바일 검증.
- API/Data: 기존 링크 계약/활성화 정의 검토. 새로운 추적/개인정보/유료 분석 도입 없음.
- SRE/Release: 선택 범위의 배포·되돌림 확인.
- Security/QA: 가상 예시 고지·URL/권한/슬롯·수집 항목 유지·동의/비용 gate 검토.

실제 실행 소유자는 단일 `orchestrator`입니다. 역할별 별도 실행 기록·스케줄러를 생성하지 않습니다.

## 범위와 측정

- 포함: 하나의 목적별 공개 가이드와 예시, 관리 화면의 링크 제목 작성 프리셋. 구현 전 현재 제품을 조사하고 기존 패턴을 재사용합니다.
- 제외: 고객 데이터 복사·레이아웃 전면 개편·자동 링크 생성·새 보상·결제·외부 메시지·통계 대시보드·새 추적 식별자.
- 기준선과 측정 한계는 연결한 팀별 조사 문서가 원본입니다. 배포 후 기존 지표의 실사용자 수·첫 보이는 링크 생성자·가입 수를 확인하되 페이지별 전환율이나 인과 효과로 표현하지 않습니다. 가입자 5명 미만은 표본 부족이며 5명 이상도 통계적 성공을 뜻하지 않습니다.
