## 목적

협업 문의용 프로필을 만들려는 크리에이터에게 완성 예시·실제 작성 방법·링크 목적별 제목 프리셋을 제공해 처음부터 무엇을 써야 하는지 정하게 합니다. 공개 가이드는 신규 유입을 위한 마케팅 자산으로도 사용합니다. 사용자 요청과 운영자 위임에 따른 AI 승인입니다. 효과는 아직 검증되지 않았습니다.

## 수용 기준

- [ ] 착수 시 현재 화면과 기존 가이드를 읽고 중복 기능을 확인한 뒤, 제품 요구·기술 설계·디자인 인계를 기존 절차로 확정합니다. 새 공개 인증 경로 없이 기존 `/docs`와 관리 화면을 재사용합니다.
- [ ] 공개 가이드는 협업 문의용 링크 구성 예시, 무료 범위, 직접 작성 단계, 가입 동선을 제공합니다. 일반 인스타그램 가이드의 복제나 경쟁사 콘텐츠 복사는 하지 않습니다.
- [ ] 완성 예시는 가상의 예시라고 명시하며 실제 고객·성과·후기인 것처럼 보이지 않습니다. 운영 계정/랜딩을 만들거나 다른 크리에이터 콘텐츠를 무단 사용하지 않습니다.
- [ ] 관리 화면에서 협업 문의/대표 작업/주요 채널 목적을 고르면 해당 목적의 링크 제목을 제안합니다. URL은 사용자가 직접 입력합니다. 선택만으로 저장·공개하거나 기존 링크/프로필을 덮어쓰지 않습니다.
- [ ] 프리셋 없이 기존 편집도 그대로 가능하며, 기존 URL 안전 검사·링크 한도·권한·저장 오류 처리 계약을 재사용합니다. 예시 링크는 사용자에게 자동 저장하지 않습니다.
- [ ] 문서 목록/기존 안내에서 공개 가이드를 찾을 수 있고 기존 Google 가입·관리 화면 흐름과 연결됩니다. `0164` CTA 측정 대상 문구는 별도 근거 없이 재변경하지 않습니다.
- [ ] localhost에서 390px·1280px 실제 가이드·예시·목적 선택·사용자 URL 저장과 실패/한도 상태를 확인합니다. 실제 링크 저장만 기존 활성화 집계에 반영되고 예시 열람은 성과에 포함되지 않습니다.
- [ ] CI→guard→main→Deploy→운영 주소 검사 근거를 기록하고 배포 시각·7일 뒤 점검일·되돌림 방법을 남깁니다.

## 팀별 소유 과제

- Product: 협업 문의 사용자 시나리오·제목 프리셋과 첫 링크 완료 기준 확정.
- Research: 아래 조사에서 사실·가설·보류 대안과 추가 사용자 근거 검토.
- Growth/Marketing: 실제 기능 기반 가이드·타깃 문안·내부 링크. 외부 게시/초대는 `0153` 승인 후에만 실행.
- Web/UX: 가상 완성 예시와 목적 선택/직접 입력 UX·모바일 검증.
- API/Data: 기존 링크 계약/활성화 정의 검토. 새로운 추적/개인정보/유료 분석 도입 없음.
- SRE/Release: 선택 범위의 배포·되돌림 확인.
- Security/QA: 가상 예시 고지·URL/권한/슬롯·수집 항목 유지·동의/비용 gate 검토.

실제 실행 소유자는 단일 `orchestrator`입니다. 역할별 별도 실행 기록·스케줄러를 생성하지 않습니다.

## 범위와 측정

- 포함: 하나의 목적별 공개 가이드와 예시, 관리 화면의 링크 제목 작성 프리셋. 구현 전 현재 제품을 조사하고 기존 패턴을 재사용합니다.
- 제외: 고객 데이터 복사·레이아웃 전면 개편·자동 링크 생성·새 보상·결제·외부 메시지·통계 대시보드·새 추적 식별자.
- 기준선과 측정 한계는 연결한 팀별 조사 문서가 원본입니다. 배포 후 기존 지표의 실사용자 수·첫 보이는 링크 생성자·가입 수를 확인하되 페이지별 전환율이나 인과 효과로 표현하지 않습니다. 가입자 5명 미만은 표본 부족이며 5명 이상도 통계적 성공을 뜻하지 않습니다.

### 자사 사이트용 원고

아래는 기존 협업 가이드에 넣을 완성 원고입니다. 아직 사이트에 게시되지 않았습니다. 새 프리셋 기능이 이미 있다고 설명하지 않으며 현재 기능만 사용합니다.

> **협업 문의용 링크, 무엇부터 넣을까요?**
>
> 모든 링크를 한꺼번에 채울 필요는 없어요. 내가 만든 작업 하나와 연락받을 곳부터 준비해 보세요.
>
> **가상의 구성 예시 — 실제 고객·후기·성과 사례가 아닙니다.**
>
> - 대표 작업 보기: 처음 방문한 사람이 내 작업을 바로 볼 수 있는 영상·작품·포트폴리오 페이지.
> - 협업 문의하기: 내가 관리하고 실제로 문의를 받을 수 있는 웹 문의 폼이나 연락 안내 페이지.
> - 주요 채널 보기: 지금 활동하고 있는 내 채널.
>
> 먼저 실제 주소가 준비된 링크 하나를 골라요. **페이지 편집 → + 링크 추가**에서 표시 이름과 `https://` 또는 `http://`로 시작하는 주소를 직접 입력하고 **저장**을 눌러요. 이메일 주소 자체나 `mailto:` 대신, 연락 방법을 안내하는 웹페이지 주소를 사용하세요. 문의 폼이 없다면 대표 작업부터 넣어도 돼요. 새 외부 서비스 가입은 필요하지 않아요.
>
> 주소가 없으면 제목만 먼저 생각해 두고 저장은 나중에 해요. 예시 주소를 내 페이지에 넣거나 다른 사람의 작업을 내 작업처럼 소개하지 않아요. 썸네일·설명·여러 링크는 선택 사항이에요.
>
> 저장한 링크가 미리보기에 보이는지 확인하고 내 크리링 링크를 복사해요. 어디에 공유할지는 내가 정해요. 공유·홍보 게시나 이벤트 신청이 링크 작성의 필수 조건은 아니에요.
>

### 완성 자사 소재: 목적을 하나 정하는 시작 카드 원고

아래는 0168 기존 협업 글 보강에 사용할 준비 원고이며 미게시입니다. 별도 캠페인 카드·진행 저장을 새로 만들지 않습니다.

> **오늘은 링크 하나의 목적부터 정해요**
>
> 방문자에게 무엇을 먼저 보여 주고 싶나요?
>
> - 작업을 보여 주고 싶다면: **대표 작업 보기**
> - 연락받을 곳을 알려 주고 싶다면: **협업 문의하기**
> - 활동 중인 채널로 안내하고 싶다면: **주요 채널 보기**
>
> 실제 주소가 있는 것 하나만 골라도 괜찮아요. 문의 폼이 없다면 작업이나 채널부터 시작하세요. 페이지 편집에서 링크를 추가하고 표시 이름과 실제 웹 주소를 직접 입력한 뒤 저장해요. 위 문구는 제목 예시이며 실제 고객이나 성과 사례가 아니에요.
>
> 저장한 항목이 미리보기에 보이면 첫 링크 준비를 마친 거예요. 내 크리링 주소를 복사해 두고 공유할 곳은 직접 정하세요. 외부 게시·팔로우·좋아요·이벤트 신청은 필수가 아니에요.
>
> 더 많은 링크가 필요하면 관리 화면에 현재 표시되는 이벤트 조건을 확인하세요. 보너스는 명시적으로 신청한 경우에만 적용되며, 첫 링크 작성에는 신청이 필요하지 않아요.

위 원고는 앞선 완성 가이드의 도입 소재이며 둘을 별도 페이지로 중복 게시하지 않습니다. 키트 제목 선택 기능의 출시 전에는 해당 기능이 이미 있다고 안내하지 않습니다. 인스타그램 붙여 넣기 자체는 기존 안내의 선택 동선으로 두고, 캠페인 참여 확인/성과 조건으로 사용하지 않습니다.
