# 0197 Instabio 공개 페이지 가져오기

- 단계: 티켓
- 역할: orchestrator
- 상태: 검증
- 종류: 기능
- 우선순위: P1
- 작성일: 2026-11-06

## 목적

사용자가 제공한 Instabio 상품 링크를 수동 복사 없이 기존 크리링으로 옮긴다.

## 수용 기준

- [x] 미리보기는 DB 변경 없이 원본 링크·이미지·순서를 보여 준다.
- [x] 선택 저장·중복 건너뛰기·한도·프로필 명시 교체가 동작하며 기존 링크를 보존한다.
- [x] 외부 요청 경계와 인증·실패·동시성 HTTP 회귀가 통과한다.
- [x] 실제 원본으로 localhost 모바일/데스크톱 UI·저장·이미지를 확인한다.
- [x] 영향 범위 검증과 변경 기록을 완료한다.

## 범위

- 포함: shared 계약, API 가져오기/배치 저장, 웹 미리보기, 회귀와 문서.
- 제외: 다른 제공자·통계/디자인 복제·사용자 운영 데이터의 대리 이전.

## 위험·복구

외부 비공식 공개 데이터 구조 변경은 오류로 알린다. 링크·프로필 저장은 원자적이며 기존 데이터는 삭제하지 않는다. 운영 배포는 GitHub Actions만 사용한다. 저장 실패 후 미참조 이미지 파일이 남을 수 있는 기존 업로드 경계를 유지한다.
