# 0160 AI 운영자 런타임 비용 승인 게이트

- 단계: 티켓
- 역할: orchestrator
- 상태: 완료
- 종류: 운영
- 우선순위: P0
- 작성일: 2026-10-11

## 목적

운영팀 헌장의 사람 승인 경계를 자동 실행 프롬프트에도 직접 주입해, 20분 주기 AI 운영자가 비용이 0원인 경우에도 결제·광고·유료 도구·외부 홍보·사람 계정 변경·법률/개인정보 위험 수용·되돌릴 수 없는 운영 DB 변경을 사람 승인 없이 실행하지 않게 합니다.

## 수용 기준

- [x] 실행 프롬프트가 운영팀 헌장을 매 실행 읽도록 합니다.
- [x] 사람 승인 전 금지 작업과 `finish --next` 기록 형식을 명시합니다.
- [x] 저장소 문서 검사와 PR CI를 통과합니다.
- [x] 비밀값·토큰·결제 정보는 변경하거나 기록하지 않습니다.
