- 확인일: 2026-10-07 (공개 페이지·도움말·요금 페이지·앱 스토어 기준. 세 서비스 모두 사용자 계정으로 로그인해 편집 화면도 직접 확인함: 리틀리 무료 계정, 인포크링크 베이직 플랜, 인링크 인플루언서 계정. [광고 블록과 광고 제거](#광고-블록과-광고-제거2026-10-09-보강) 절은 2026-10-09 확인)
- 조사 질문: 인스타그램 크리에이터가 링크 페이지를 만들어 공유하고 방문자가 링크를 누르기까지, 세 서비스는 화면을 어떻게 구성했는가? 그중 크리링 MVP 화면(공개 랜딩, 링크 관리, 내 크리링)과 디자인 시스템에 옮길 만한 것은 무엇인가?

## 핵심 흐름과 UX 패턴

### 처음 만들기

- 인포크: 공식 가이드 순서가 ① 디자인 설정(레이아웃·배경색) → ② 관리자 페이지에서 블록 설정 → ③ 관리자 페이지에서 아이디를 눌러 주소 복사입니다. 모바일·노트북 어디서나 편집한다고 안내합니다. https://blog.inpock.co.kr/guide-getting-started-1/
- 인링크: 가입하면 마이링크가 자동으로 만들어지고, 프로필·SNS 채널을 연동한 뒤 첫 캠페인에 지원하는 흐름입니다. 사진·소개·SNS·포트폴리오는 별도 편집 없이 마이페이지 입력값으로 채워진다고 도움말에 적혀 있습니다. 인플루언서 소개 페이지의 예시 화면에는 '마이링크 편집'에서 구역을 켜고 끄고 손잡이로 순서를 바꾸는 모습이 있어, 도움말과 소개 페이지 설명이 다릅니다. https://inlink.to/help/article/influencer-getting-started , https://inlink.to/for/influencer
- 리틀리: 블록을 추가하고 끌어서 순서를 바꾸면 미리보기에 바로 반영된다고 자사 블로그에 적혀 있습니다. 편집 화면에서 확인한 새 페이지에는 단일 링크와 그룹 링크 블록이 빈 채로 들어 있었습니다(공개 페이지 데이터의 `type`은 `link`와 `productLink`). https://start.litt.ly/blog/insta-profile-link-services-comparison-2026 , https://litt.ly/shaul

### 방문자가 보는 공개 페이지

- 세 서비스 모두 휴대폰 세로 한 열입니다. 위에 프로필(사진·이름·소개)이 오고 아래로 블록·구역이 이어집니다.
- 인포크 예시 세 페이지는 SNS 아이콘이 모두 아래쪽(`bottom`)에 있었고, 맨 위 링크에 스티커를 붙여 눈에 띄게 한 페이지가 있었습니다. https://link.inpock.co.kr/deelisa
- 인링크 마이링크는 아바타·닉네임·평점 → 소개 → 제안하기·메시지 보내기·포인트 선물하기 버튼 → 포트폴리오 → SNS 채널(팔로워·참여율) → 분야 TOP3 → 숏폼·게시물 → 협업 이력 → 받은 리뷰 → 방명록 순서였습니다. 크리에이터 콘텐츠보다 브랜드가 평가하는 정보가 많습니다. https://inlink.to/10959
- 리틀리 예시는 배경 이미지·큰 카드형 링크·동영상·음악·후원처럼 블록이 다양했고, 링크 하나를 강조 표시(`emphasized`)한 페이지가 있었습니다. 공유·구독 버튼이 기본으로 켜져 있습니다. 필수값(URL·링크 목록)이 빈 블록은 공개 페이지에 나타나지 않아, 빈 새 페이지는 프로필 자리와 하단 배지만 보였습니다. https://litt.ly/zoee , https://litt.ly/tovmusic , https://litt.ly/shaul

### 화면 구성과 저장

- 왼쪽에 휴대폰 모양 미리보기, 오른쪽에 편집 패널을 둡니다. 편집 패널 위 탭은 `페이지`·`디자인`·`분석`·`관리`·`마케팅` 다섯 개이고 주소가 바뀝니다(`/page`, `/design`, `/report`, `/manage`, `/marketing`). 미리보기 아래 막대에 주소 `litt.ly/shaul`과 설정(연필)·복사·공유 아이콘이, 맨 왼쪽에 설정(톱니)·`페이지 추가`·계정 메뉴가 있습니다.
- 저장 버튼이 없습니다. 레이아웃 같은 선택지를 바꾸면 새로고침 뒤에도 바뀐 값이 남아 있어, 바꾸는 즉시 저장됩니다.
- 미리보기에서 필수값이 빈 블록은 점선 상자와 빨간 안내 문구("url을 정확히 입력해 주세요", "링크를 하나 이상 추가해 주세요")로 보입니다. 같은 블록은 공개 페이지에 나타나지 않습니다.

## 결론

### 따라 할 것

- [AI 제안] 공개 랜딩은 지금 PRD 구성(프로필 → SNS → 링크 → 포트폴리오)을 유지합니다. 세 서비스 모두 프로필을 맨 위에 둔 세로 한 열이고, 크리링 DESIGN.md의 "크리에이터가 주인공" 방향과 같습니다.
- [AI 제안] 링크 카드는 두 형태를 같은 카드 안에서 소화합니다. 썸네일이 없으면 파비콘과 제목만, 있으면 왼쪽 썸네일입니다. 인포크 simple/thumbnail, 리틀리 작은·중간·큰 카드와 같은 구분이며 R5 수용 기준 ④⑤와 맞습니다. 별도 표시 종류를 고르는 화면은 두지 않습니다.
- [AI 제안] 링크별 숨기기와 끌기 정렬은 세 서비스 모두 갖춘 기본기라, R18대로 관리 화면 한 곳에서 제공합니다.
- [AI 제안] 공개 랜딩 맨 아래의 "크리링으로 만든 페이지" 한 줄은 업계 관행과 같습니다. 이후 유료에서 지울지는 사업 결정입니다.
- [AI 제안] 업로드·불러오기 실패 상태를 먼저 다듬습니다. 두 앱 리뷰의 불만 상당수가 흰 화면·이미지 업로드 실패·로그인 오류였습니다. 크리링 프로필 사진·썸네일·포트폴리오 이미지 업로드에 실패 이유와 다시 시도 행동을 반드시 보여 줍니다(DESIGN.md "모든 화면은 로딩·성공·빈 상태·오류").
- [AI 제안] 처음 쓰는 크리에이터에게 "주소 복사 → 인스타그램 프로필에 붙여넣기"를 단계로 보여 줍니다. 인링크 마이링크 관리는 3단계 안내와 "다음 한 걸음" 카드로 남은 칸을 하나씩 권합니다. 크리링 `/me`의 단축 URL 확인·복사(R1)와 같은 방향이라 문구와 순서만 참고합니다.
- [AI 제안] 링크 주소를 넣으면 제목·이미지를 미리 채우는 것은 인포크 링크 블록의 기본 동작입니다(OG 수집). 같은 수집이 쿠팡 상품 주소에서는 HTTP 400으로 실패했습니다. 이를 다루던 0045(블록·스와이프 카드)는 2026-10-08 사용자 결정으로 폐기되어 크리링에 넣을 계획이 없습니다.

### 피할 것

- [AI 제안] 공개 페이지에 플랫폼 행동 버튼을 늘어놓지 않습니다. 인링크 마이링크는 제안·메시지·포인트 선물 버튼과 평점·팔로워·리뷰가 앞에 와서 방문자가 크리에이터 링크까지 내려가야 합니다.
- [AI 제안] 꾸미기 선택지를 MVP에 넣지 않습니다. 인포크·리틀리는 폰트 6종 이상·버튼 모양·배경 이미지·스티커를 주지만, 크리링은 디자인 시스템 한 가지로 시작한다는 기존 결정(0020)을 유지합니다.
- [AI 제안] 배경 이미지 위에 어두운 덮개를 씌우는 방식(인포크)은 대비 확인이 어렵고 SNS 공식 아이콘 색과 다툴 수 있어 쓰지 않습니다.
- [AI 제안] 관리 화면을 유료 안내로 채우지 않습니다. 리틀리는 첫 진입 광고 팝업, 탭마다 유료 배너, 선택지마다 자물쇠가 있어 무료 사용자가 지금 쓸 수 있는 것을 매번 가려내야 합니다. 크리링이 유료(R6·R13)를 열 때도 한도에 닿은 순간에만 안내합니다(R13 한도 안내와 같은 방식).

### 차별화 기회

- [AI 제안] 무료 단축 주소와 그 방문 데이터. 인포크는 간단 주소가 유료이고, 크리링은 단축 URL을 기본 제공하며(R6) 모든 외부 진입을 단축 주소로 기록합니다(R7). 공유 화면에서 "이 주소를 인스타그램 프로필에 넣으세요"를 가장 먼저 보여 주는 것이 크리링다운 첫 경험입니다.
- [AI 제안] 군더더기 없는 랜딩. 세 서비스 모두 블록이 늘면서 페이지가 길고 다양해졌습니다. 크리링은 리스트형 한 구역으로 "누를 곳이 분명한 페이지"를 강점으로 삼을 수 있습니다.
- [AI 제안] 무료 주소 변경. 리틀리 무료 계정은 주소 입력란이 잠겨 있고 인포크는 간단 주소가 유료입니다. 크리링은 R8대로 무료로 바꾸고 옛 주소를 90일 동안 새 주소로 연결합니다.

크리링 광고 블록·배너 슬롯 요구(PRD R20~R22, work item `docs/work/product/0062-ad-banner-block-prd.md`)의 근거로 공개 자료만 확인했습니다. 리틀리 광고 블록은 자사 블로그 글이 유일한 출처이며, 편집 화면에서 광고 블록을 추가해 보지는 않았습니다.

- 리틀리 광고 블록(리틀리AD)은 "리틀리가 광고를 연결해 내 프로필 페이지에 노출하고, 발생한 수익을 크리에이터에게 분배"하는 서비스입니다. 수익은 광고 배너의 노출과 클릭으로 생기고 클릭 단가는 광고마다 다르며 고정 단가가 아닙니다. https://start.litt.ly/blog/side-hustle-jobs-2026-littly-ad
- 시작은 `블럭 추가` → `광고` 블럭 → 광고 레이아웃 선택이고 별도 심사가 없습니다. 광고 블록은 여러 개 만들 수 있고("여러 개 생성할수록 더 높은 수익"), 블록 순서를 자유롭게 바꾸며, 언제든 OFF하면 즉시 멈춥니다. 같은 글.
- 정산은 매주 금요일 자동 입금, 최소 100원, 출금 신청 없음, 수익은 `관리 → 광고수익관리`에서 봅니다. 같은 글 안에서 정산 기준 기간이 "이번 주 월~금 → 다음 주 금요일"과 "저번 주 수요일~이번 주 화요일 → 이번 주 금요일" 두 가지로 적혀 있어 정확한 기간은 확인하지 못했습니다. 같은 글.
- 세금은 프리랜서 사업소득으로 3.3%를 원천징수하고 입금하며, 계좌 인증 때 받은 주민등록번호를 세무 처리에 씁니다. 만 19세 이상 개인회원(사업자등록 없음)만 쓸 수 있고 법인 계좌는 안 됩니다. 판매 블록 수익과 따로 정산합니다. 같은 글.
- 편집 화면 첫 진입 팝업 문구는 "버튼 하나만 켜면, 자동으로 광고비가 들어와요"였습니다(위 [리틀리 편집 화면](#화면-구성과-저장), 2026-10-07).
- 인포크 요금 페이지는 Pro(월 5,900원) 기능에 `광고 없음`을 둡니다. 무료(Basic)에서 광고가 어느 화면(공개 페이지·관리 화면)에 나오는지는 요금 페이지에 적혀 있지 않고 확인하지 못했습니다. https://www.inpock.co.kr/plan
- Google 게시자 정책은 게시자 콘텐츠가 없거나 가치가 낮은 화면, 알림·이동(navigation) 용도 화면, 감사·종료·오류 같은 막다른 화면에 Google 광고를 허용하지 않습니다. 링크 몇 개뿐인 링크 페이지에 AdSense를 붙이면 이 정책에 걸릴 수 있습니다(추론, 심사해 보지 않음). https://support.google.com/publisherpolicies/answer/11112688

정리: 리틀리는 "크리에이터가 켜는 선택 블록 + 수익 배분 + 주간 자동 정산", 인포크는 "유료 플랜이면 광고 없음"입니다. 크리링 사용자 결정(2026-10-09)은 둘을 합친 형태입니다. 무료 랜딩에는 광고 블록이 반드시 있고 위치만 바꿀 수 있으며 수익은 크리에이터와 나눕니다. 유료(이번에는 운영자 수동 부여)이면 그 자리가 크리에이터 배너 슬롯이 됩니다. 반영 위치는 [PRD](../crelink.md#요구사항) R20~R22입니다.
