CRELINK / 영상 대표작 공개 준비

영상 한 편의 주소와
내 역할을 함께 정리하세요.

공개 가능한 원본 시청 페이지를 이미 가진 영상 크리에이터를 위한 작성용 워크시트입니다. 작품 제목·본인 역할·볼 구간·한 줄 설명을 정리하고, 필요한 경우에만 공개용 문의 웹페이지를 더하세요. 영상 파일이나 썸네일 업로드는 필요 없습니다.

크리링 회사의 AI 운영자(PM)가 제작한 자사 안내 자료입니다. 고객 사례·후기·모집 성과가 아니며, 실제 수요와 성장 효과는 관측되지 않았습니다.

이곳은 크리링 저장 화면이 아닙니다. 입력과 생성 결과는 이 페이지의 메모리에만 있으며 새로고침하거나 다시 열면 사라집니다. 결과 생성·수정·초기화는 외부 호출·저장소·추적·업로드·자동 공개를 하지 않습니다. 결과는 화면에서 직접 선택해 복사할 수 있으며 클립보드 권한을 요구하지 않습니다.

아래 공식 안내 링크를 직접 누르면 외부 페이지로 이동합니다. 이 자료는 입력 URL을 열거나 검사하지 않습니다.

01 · 공개할 권한이 있는 영상만 작성

원래 영상을 볼 수 있는 웹페이지 주소를 직접 입력하세요. 다운로드·관리자·초대용 비밀 링크는 쓰지 마세요. 이 결과는 임베드나 영상 재생 기능이 아닙니다.

구간 안내는 설명 문구일 뿐입니다. 시간 링크를 만들거나 재생 위치를 자동 지정하지 않습니다.

본인이 운영하고 공개해도 되는 문의 폼·문의 웹페이지 주소만 적으세요. 이메일 주소 자체나 mailto:는 사용하지 않습니다. 문의처가 없으면 대표 영상만 정리해도 됩니다.

작성 후 ‘결과 생성’을 누르세요. 생성은 저장이나 공개가 아닙니다.

02 · 직접 복사할 작성 결과

결과 전체 또는 필요한 부분을 드래그해 복사하세요. 아래 ‘결과 전체 선택’ 후 Ctrl+C / ⌘C도 가능합니다. 수정은 입력란에서 하고 다시 생성하세요. 


      

      

        

          일부 공개도 비밀 보관이 아닙니다. URL을 아는 사람이 보거나 재공유할 수 있습니다.
          계약·의뢰인·등장 인물의 공개 동의, 음악·이미지 등 제3자 권리와 실제 본인 역할을 먼저 확인하세요. 비공개 고객
          영상·미공개 작업·계약서·개인 연락처·비밀번호·접근 토큰은 입력하지 마세요. 공개할 권한이 불확실하면 해당 작업을
          제외하세요.
        

        

          Vimeo를 쓴다면 원본 시청 URL의 privacy hash를 제거하지 마세요. 공개 Portfolio는 개별 영상의 비공개 설정보다
          우선할 수 있으므로 실제 전달할 주소의 공개 범위를 확인하세요. 일부 공개·비밀번호 등의 유료 옵션을 새로 구매할
          필요는 없습니다.
        

        

          HTTP(S) 형식 확인은 안전성·공개 권한·접근 가능성 보증이 아닙니다. 이 자료는 원본 URL을 자동 열기·접속
          검사·권리 인증하지 않으며 입력 URL은 결과에서도 클릭 링크로 만들지 않습니다.
        

      

      

        
03 · 크리링에서 직접 입력하고 명시적으로 저장

        
    
          
  1. 
            크리링의 ‘페이지 편집’ → ‘+ 링크 추가’에서 결과의 표시 이름과 원본 시청 주소를 직접 입력합니다. 선택 항목인
            설명에는 작품 제목·본인 역할·볼 구간·한 줄 설명을 옮기고 ‘저장’을 누릅니다.
          
    2. 
          
  2. 
            문의 URL을 준비했다면 별도의 ‘+ 링크 추가’에서 ‘협업 문의하기’와 그 주소를 직접 입력하고 ‘저장’합니다.
            문의처 등록은 선택입니다.
          
    3. 
          
  3. 
            저장 뒤 ‘공개 페이지 열기’에서 실제 링크를 확인하고, 비로그인 창에서도 원본 시청 페이지와 문의처가 열리는지
            직접 확인하세요. 편집 미리보기는 미저장 입력도 보이므로 공개 확인을 대신하지 않습니다.
          
    4. 
          
  4. 
            주소 막대의 ‘복사’로 내 크리링 주소를 복사할 수 있습니다. SNS 프로필에 붙일지와 외부 공유 여부는 직접
            결정하세요. 원본 공개 범위가 바뀌면 다시 확인하세요.

          서비스 조건: 단축 주소·주소 변경과 방문자에게 보이는 외부 링크 기본 5개는 무료입니다. 무료
          페이지에는 삭제·숨기기가 불가능한 크리링 자체 광고 배너 자리 1개가 있으며, 게시 중인 광고가 없으면 방문자에게
          보이지 않습니다.
        

        

          자동 수집·자동 저장·자동 공개·협업 매칭 기능을 안내하는 자료가 아닙니다. 조회수·문의 증가·협업 성사를 보장하지
          않습니다. 인쇄본과 복사한 내용은 직접 보관하고 공개 전에 검토하세요.
