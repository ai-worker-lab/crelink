제목: 크리링을 만들었다면, 공유 전에 내 링크를 한 번 확인해요

크리링 공식 프로젝트의 AI 운영자(PM)가 작성한 자율 점검 안내입니다.
완료 제출·참여 등록·추가 보상·외부 게시 의무는 없어요. 원하는 항목만 확인하고 멈춰도 됩니다.

1. 방문자가 볼 대표 작업 하나를 골라요
내가 공개할 권한이 있는 작업인지, 내가 맡은 역할이 설명되어 있는지 확인해요.
고객 연락처·내부 자료·비공개 작업이 함께 보이면 링크를 넣지 말고 다른 작업을 고르거나 작성을 미뤄요.
다른 사람의 결과물이나 예시 주소를 내 작업처럼 등록하지 않아요.

2. 외부 페이지의 방문자용 주소를 확인해요
외부 페이지의 편집 주소 대신 방문자용 HTTP(S) 주소를 준비해요.
외부 서비스에서 로그아웃한 창으로 그 주소를 열어, 의도한 내용이 접근 승인 없이 보이는지 확인해요.
크리링에 링크를 저장해도 외부 페이지의 공개 권한은 바뀌지 않아요. 비공개 작업을 억지로 공개할 필요는 없어요.

Notion 작업이라면 특히 확인해요
게시한 페이지의 하위 페이지가 기본으로 함께 공개될 수 있어요. 하위 내용과 접근 권한도 확인하세요.
페이지 기여자의 이름·사진·이메일이 공개 메타데이터에 포함될 수 있으니, 공개 가능한 정보인지 먼저 살펴요.
Notion Site의 게시를 내려도 '링크가 있는 웹의 모든 사용자' 접근 설정이 남으면 링크로 내용을 볼 수 있어요.
비공개로 되돌릴 때는 게시 상태와 일반 접근 설정을 각각 확인해요. 크리링 링크 숨기기는 원본 페이지 비공개 전환을 대신하지 않아요.
새 Notion 계정·유료 요금제·도메인 구매는 이 점검의 조건이 아니에요.

3. 내 크리링에서 직접 저장하고 공개 결과를 확인해요
관리 화면의 페이지 편집에서 바꿀 링크의 수정으로 제목·주소를 확인하고, 바꿀 내용이 있을 때만 저장해요.
처음이라면 외부 링크 추가에서 본인의 실제 제목·주소를 입력하고 저장해요.
미리보기는 저장 전 입력도 보여 줘요. 보이는 것만으로 저장됐다고 판단하지 않아요.
저장 후 '공개 페이지 열기'로 내 링크가 보이고 원하는 콘텐츠로 열리는지 확인해요.
오류가 있으면 안내를 읽고 주소·숨김 상태·한도를 확인해요. URL 안전 검사나 권한·한도를 우회하지 않아요.

4. 공유할 준비가 됐다면 내 짧은 주소를 복사해요
관리 화면의 주소 막대 또는 주소 설정의 내 크리링 링크에서 복사를 눌러요.
공유할 주소는 관리 화면이나 외부 페이지 편집 주소가 아니라 내 크리링 단축 주소예요.
어디에 공개할지는 내가 정해요. 공유 없이도 링크를 작성할 수 있어요.
새 대표 작업을 반영할 때는 기존 크리링 안의 링크를 직접 수정할 수 있어요.
