## 1. 서비스 개요 (Service Overview)

- **서비스명**: 크리링 (CreLink - Creator + Link)
- **슬로건**: 크리에이터의 가치를 브랜드와 링크하다
- **핵심 가치**
  - **신속성**: 대행사 단계를 건너뛰고 광고주와 크리에이터가 플랫폼에서 직거래
  - **투명성**: 성과 데이터 기반의 군더더기 없는 매칭
  - **성장성**: 롱테일 마이크로 크리에이터를 위한 유입 가이드 제공

## 3. 초기 비즈니스 모델 (Business Model)

초기에는 가입자 확보(Cold Start 해결)를 위해 중개 수수료를 최소화하고, 단계적으로 수익 모델을 확장한다.

1. **원고료 정산 수수료 (초기 면제 후 전환)**: 광고주가 크리에이터에게 원고료를 지급하는 캠페인에 안전 결제(에스크로)를 제공하고, 결제 대금의 5~10%를 수수료로 부과한다. (요율은 가설, 검증 후 확정)
2. **광고주 프리미엄 패키지**: 목록 최상단 노출, 특정 카테고리 크리에이터 대상 타깃 푸시 알림 패키지 판매
3. **크리에이터 멤버십**: 포트폴리오 멀티링크 툴킷 및 정밀 분석 리포트 유료 제공

> 결제 정산은 MVP 범위 밖이다(5장 2단계). 에스크로·대금 보관은 직접 운영 시 전자금융업 등록 이슈가 있으므로 PG사 에스크로/정산 대행 상품 연동을 전제로 설계한다.

## 4. MVP (최소 기능 제품) 구축 요건

핵심 흐름 **캠페인 열기 → 크리에이터 지원 → 수동 선정 → 결과 제출 및 검수**만 구현하여 빠르게 시장 반응을 확인한다.

### 4.1. 기능 스펙 정의

- **회원가입 및 계정**: 카카오/네이버 소셜 로그인 연동. 가입 시 '광고주'와 '크리에이터' 역할 필수 분리
- **캠페인 등록 (광고주)**: 제목, 카테고리, 제공 내역(제품/서비스), 모집 인원, 가이드라인(키워드), 마감일 입력 폼 제공
- **지원 및 선정**: 광고주 마이페이지에서 지원한 크리에이터 목록을 확인하고, 수동으로 '선정' 버튼을 눌러 확정
- **캠페인 참여 (크리에이터)**: 전체 캠페인 리스트 조회 후 '한 줄 어필'과 함께 지원. 선정 완료 시 리뷰 결과물 URL(블로그/인스타그램 링크 등) 제출
- **어드민 검수 (관리자)**: 크리에이터가 제출한 URL의 정상 작동 여부를 관리자가 확인 후 최종 '완료' 처리
- **광고 표시 의무**: 리뷰 가이드라인에 경제적 이해관계(협찬·광고) 표시 문구를 기본 포함하고, 어드민 검수 항목에 표시 여부를 포함한다 (공정위 「추천·보증 등에 관한 표시·광고 심사지침」 대응)

### 4.2. MVP 개발 효율화 전략

- **반응형 웹(Responsive Web) 선개발**: 앱 개발 공수를 배제하고 모바일 화면에 맞춘 웹으로 먼저 론칭
- **이메일 알림 대체**: 비용이 드는 알림톡/SMS 대신 시스템 이메일 및 서비스 내 웹 알림으로 알림 체계 최소화
- **개발 일정**: 기획 및 디자인 (2주) → 백엔드 API 및 DB 구축 (3주) → 프론트엔드 개발 및 QA (3주) → **총 8주 내 MVP 출시**

---

## 5. 향후 고도화 로드맵 (Post-MVP)

- **1단계**: SNS API 연동을 통한 크리에이터 팔로워 수 및 조회수 데이터 자동 동기화
- **2단계**: 플랫폼 내 가상 포인트 및 결제 정산 자동화 시스템 구축
- **3단계**: 숏폼 커머스 및 공동구매 링크 빌더 기능 결합
