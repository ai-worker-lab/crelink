# 모집 채널 실행 문안과 PM 실행 목록

- 상태: 사용 중 (2026-10-10 작성·AI 승인, 2026-10-12 사용자 결정으로 무료 외부 홍보를 PM 자율 실행으로 전환)
- 작성일: 2026-10-10
- 정책 갱신일: 2026-10-12. 채널 규칙 근거 확인일은 2026-10-10 ([초기 사용자 모집 조사](research/initial-user-acquisition.md#지켜야-할-법과-약관)); 실제 실행 직전 PM이 다시 확인하고 출처·확인 시각을 기록합니다.
- 관련: [PRD](crelink.md) `목표`·R23 ⑦·R24, work item `docs/work/product/0145-acquisition-channel-playbook.md`(이 문서), `docs/work/product/0153-acquisition-human-requests.md`(PM 실행 전환), `docs/work/product/0087-signup-source-attribution.md`(유입 경로 기록)

실사용자 100명 모집의 기존 단계 1·2(첫 10명, 30명) 계획과 문안을 재사용합니다. 사용자 결정(2026-10-12: “외부 홍보도 자체적으로 하라. 지출, 결제만 사람 승인 필수로 한다”)에 따라 PM은 합법·약관 준수·수신동의가 확인된 무료 외부 게시·모집·개별 연락과 회사 채널·계정 사용, 플랫폼이 허용하는 무료 회사 계정 구성을 사람 승인 없이 결정·실행합니다. 사전 사람 승인은 실제 지출·결제·유료 구독/크레딧·비용 발생 약정에만 필요합니다. 과거 조사와 완료 티켓의 사람 실행 경계는 당시의 역사 기록이지 현재 정책이 아닙니다.

실제 외부 공개는 PM이 인증·멈춤 통제와 아래 규칙·근거를 확인한 뒤 수행합니다. 전문 worker는 조사·문안·로컬 검증 결과와 실행 근거를 PM에게 인계하며 운영 credentials를 받지 않습니다. 회사 계정 접근이나 정상 인증이 불가능하면 실제 인증/접근 blocker로 기록하고, 다른 실행 가능한 무료 채널을 선택할 수 있습니다. 사람 개인계정 사칭, 비밀값 전달·공개, CAPTCHA/OTP 우회, 데이터 파괴는 금지이며 사람 승인으로 우회할 수 없습니다.

이 문서는 법률 자문이 아닙니다. 법·약관 해석은 조사 문서의 `(추론)`을 따르며 법률 검토 전입니다.

## 쓰는 방법

1. PM이 [PM 실행 목록](#pm-실행-목록)에서 법·약관과 접근 전제가 확인된 무료 채널을 고릅니다. 기존 순서와 한 주 한 채널 원칙은 효과 관측을 위한 기본 계획입니다. H1의 동의·접근이 없더라도 허용된 공개 채널부터 실행할 수 있고, PM이 순서를 바꾸면 근거를 남깁니다.
2. 그 채널의 [공통 규칙 확인표](#공통-규칙-확인표), 채널별 확인 항목, 비용·인증·멈춤 상태를 확인합니다. 충족하지 않거나 근거가 미확인이면 그 행동은 하지 않습니다. 무료인지 모르는 상태를 비용 0으로 쓰지 않습니다.
3. 문안의 `<…>` 자리만 채우고, 사실(숫자·기능)은 확인 없이 바꾸지 않습니다. 문안은 기존 운영 기능 기준입니다. 기능·행사 조건이 바뀌면 PRD/제품 결정 절차로 이 문서를 함께 고칩니다. 비용 없는 새 슬롯·이벤트 조건은 사람에게 재승인 요청하지 않습니다.
4. PM이 실제 제출/게시/발송 시각, 채널 규칙 출처·확인 시각, 확인 가능한 공개 URL과 결과를 실행 목록에 기록합니다. 제출과 공개를 구분하고 거절·접근 blocker·철회·관측도 남깁니다. 가입 수 증가로 실행일이나 게시 사실을 추정하지 않습니다.
5. 받는 사람의 이름·연락처·계정 주소·개별 대화 원문은 이 문서·work item·실행 기록에 적지 않습니다([헌장](../ops/ai-operator.md#어떤-경우에도-지킬-규칙) 개인정보 규칙). 비식별 동의 근거 참조와 개수만 기록합니다. 공개 채널·게시 URL은 원본 근거로 기록하되 개인 정보·비밀값을 포함하지 않습니다.

문안은 아래 사실만 씁니다. 원본은 코드이며, 바뀌면 이 절과 문안을 함께 고칩니다.

| 사실 | 값 | 원본 |
| --- | --- | --- |

## 채널별 문안

### 1. 지인 초대(1:1 메시지)

- 대상: 인스타그램 등에서 활동하고 프로필 링크가 필요할 만한 크리에이터 중, 회사의 광고성 메시지 수신에 이미 적법하게 동의한 사람. “이미 아는 사람”만으로는 대상이 되지 않습니다.
- 규칙: C1·C2·C4·C7·C8. 단체방·여러 명에게 같은 글을 한꺼번에 보내지 않습니다. 동의가 없으면 1-A도 보내지 않습니다. 발송 전에 법정 광고 표시·발신자 정보·수신거부 방법을 실제 채널에 맞게 확인·반영합니다.
- 확인할 곳: 안전하게 보관된 사전 동의 기록(발신자·목적·채널·범위·시각), 플랫폼의 회사/AI 발신 허용 규칙. 이 문서에는 비식별 근거 참조만 남깁니다.

1-A 기존 초안(이력 보존·발송 금지):

```text
<이름>님, 요즘 잘 지내요? 제가 크리에이터용 프로필 링크 페이지 서비스를 직접 만들었는데, 인스타그램 프로필 링크 쓰시는 분 의견이 듣고 싶어서요. 소개 링크 하나 보내도 될까요? 괜찮지 않으면 편하게 말해 주세요.
```

1-A는 초안 이력 보존용입니다. 사전 동의 없이 홍보 허락을 묻는 우회 연락 및 사람 제작자 사칭에 사용할 수 없습니다.

1-B 소개(기존 적법한 사전 동의 확인 뒤, 필수 표시를 갖춘 발송용 본문):

```text
크리링 회사의 AI 운영자(PM)가 수신동의 범위 안에서 드리는 서비스 소개예요. SNS 채널·포트폴리오·외부 링크를 한 페이지에 모아서 짧은 주소 하나로 인스타그램 프로필에 걸 수 있어요.

- 구글 계정으로 시작: https://links.shaul.kr
- 단축 주소·주소 변경 무료, 외부 링크 5개 무료(지금 이벤트 신청하면 10개)
- 무료 페이지에는 링크 사이에 크리링 배너 자리가 하나 들어가요

써 보고 불편한 점 알려 주시면 바로 고칠게요. 관리 화면의 '의견 보내기'로 남겨도 돼요.
```

### 2. 디스콰이엇 제품 등록

- 대상: 메이커·초기 창업자 커뮤니티 [디스콰이엇](https://disquiet.io/announcement).
- 규칙: C3·C4·C6. 본인 제품만 등록하고, 등록은 디스콰이엇 검토 승인 뒤 보입니다. 같은 글을 여러 번 올리지 않습니다.
- 확인할 곳: 디스콰이엇 공지·제품 등록 화면의 운영 규칙(등록 직전 다시 확인).

제품 한 줄 소개:

```text
인스타그램 프로필 링크 하나로 SNS·포트폴리오·외부 링크를 모아 보여 주는 크리에이터 랜딩페이지
```

제품 설명:

```text
크리링은 크리에이터가 SNS 채널, 포트폴리오, 외부 링크를 한 페이지에 모아 짧은 주소로 전하는 랜딩페이지 서비스입니다. 크리링 회사의 AI 운영자(PM)가 제품을 소개하고, 사용자 의견을 받으며 고치는 중입니다.

- 구글 계정으로 시작, 단축 주소와 주소 변경 무료
- 외부 링크 5개 무료, 링크 슬롯 이벤트를 신청하면 10개
- 무료 페이지에는 링크 사이에 크리링 배너 자리 1개가 들어갑니다

궁금한 점이나 불편한 점을 댓글로 남겨 주시면 고쳐서 릴리스 노트에 남기겠습니다.
https://links.shaul.kr
```

제품에 연결해 올리는 첫 글(메인 피드용):

```text
제목: 크리에이터 프로필 링크 페이지 '크리링'을 만들고 있어요

인스타그램 프로필에서 협업 제안 받을 포트폴리오와 판매·공구 링크를 같이 보여 주려는 크리에이터를 위한 서비스예요. 지금은 링크·포트폴리오·SNS 채널을 한 페이지에 모으고, 짧은 주소로 프로필에 걸 수 있어요.

써 보고 막히는 지점을 알려 주시면 가장 큰 도움이 됩니다. 크리링 회사의 AI 운영자(PM)가 제품을 소개하는 글이에요.
```

### 3. 크리에이터·마케팅 커뮤니티 홍보 게시판

- 대상: 크리에이터·1인 사업자·마케터 카페나 커뮤니티 중 **홍보 게시판이 있거나 운영자가 허락한 곳**.
- 규칙: C3·C4·C6. 한 커뮤니티에 한 번만 올리고, 다른 게시판(자유·질문)에 홍보 글을 올리지 않습니다. 댓글로 남의 글에 홍보를 달지 않습니다.
- 확인할 곳: 그 커뮤니티의 공지·게시판 규칙(홍보 허용 게시판, 등급 조건, 글머리, 횟수 제한, 회사/AI 계정의 실행 방식). 확인한 공개 규칙 URL·확인 시각과 필요한 조건을 PM 실행 목록에 기록합니다.

게시 글:

```text
[홍보] 인스타그램 프로필 링크 페이지 '크리링' (크리링 회사의 AI 운영자 PM이 소개합니다)

인스타그램 프로필 링크 하나에 SNS 채널, 포트폴리오, 외부 링크를 모아 보여 주는 페이지예요.

- 구글 계정으로 시작: https://links.shaul.kr
- 단축 주소·주소 변경 무료, 외부 링크 5개 무료(이벤트 신청 시 10개)
- 포트폴리오를 사진·설명과 함께 올려 협업 제안용 페이지로 쓸 수 있어요

사용법: https://links.shaul.kr/docs/instagram-profile-links
```

### 4. 크리링 공식 인스타그램 소개 게시물

- 선행: PM이 크리링 공식 회사 계정 개설·활용 여부를 결정하고 PRD `위험과 미정 사항`에 근거를 남깁니다. 플랫폼이 허용하는 무료 회사 계정 구성·접근·게시 방식과 정상 인증을 확인하면 사람 승인 없이 실행합니다. 무료 계정/접근 불가는 인증/접근 blocker이지 비용 승인 대기가 아닙니다. 사람 개인계정을 대신 쓰거나 인증을 우회하지 않습니다. 공식 게시 API는 프로페셔널 계정과 Meta 앱 권한 등 실제 조건이 갖춰진 경우에만 사용하며, 비용 발생 약정은 사람 사전 승인을 받습니다.
- 규칙: C1·C4·C6. 하루 1개 이하로 올립니다. 팔로우·좋아요·태그를 이벤트 조건으로 걸지 않습니다. 다른 계정에 자동·대량 댓글·DM을 하지 않습니다.
- 확인할 곳: [Instagram 이용 약관](https://help.instagram.com/581066165581870/?locale=ko_KR), [Meta 스팸 정책](https://transparency.meta.com/ko-kr/policies/community-standards/spam/).
- 프로필 링크: `https://links.shaul.kr`. 이미지는 크리링 화면 캡처(시험 데이터, 실제 크리에이터 데이터는 허락 없이 쓰지 않음)나 기존 크리링 배너(`design/first-ad-banner/`, 0086)를 씁니다.
- 회사 프로필과 게시 문맥에 크리링의 공식 제품 소개이며 AI 운영자(PM)가 작성·게시한다는 관계를 표시합니다.

게시물 1(소개):

```text
인스타그램 프로필 링크, 하나로 충분하게.

단축 주소와 주소 변경은 무료, 외부 링크도 5개까지 무료예요.

프로필 링크에서 구글 계정으로 시작해 보세요.
```

게시물 2(사용 3단계):

```text
크리링 시작은 세 단계예요.

1. 구글 계정으로 시작
2. 링크나 포트폴리오 하나 추가
3. 내 크리링 주소를 복사해 인스타그램 프로필 '링크'에 붙여 넣기

자세한 방법은 프로필 링크의 사용 안내에 있어요.
```

게시물 3(이벤트):

```text
링크 슬롯 이벤트를 하고 있어요.

관리 화면에서 이벤트를 신청하면 보이는 외부 링크가 5개 더 늘어나요(5개 → 10개). 계정당 한 번, 신청만 하면 돼요.

```
