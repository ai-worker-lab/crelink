# 모집 채널 실행 문안과 사람 요청 목록

- 상태: 사용 중 (2026-10-10 작성, 사용자 위임(2026-10-10, ADR 0015)에 따른 AI 승인)
- 작성일: 2026-10-10
- 확인일: 2026-10-10 (규칙 근거는 [초기 사용자 모집 조사](research/initial-user-acquisition.md#지켜야-할-법과-약관) 확인일 기준)
- 관련: [PRD](crelink.md) `목표`·R23 ⑦·R24, work item `docs/work/product/0145-acquisition-channel-playbook.md`(이 문서), `docs/work/product/0153-acquisition-human-requests.md`(사람 요청 실행), `docs/work/product/0087-signup-source-attribution.md`(유입 경로 기록)

실사용자 100명 모집의 단계 1·2(첫 10명, 30명)는 사람 계정이 있어야 하는 채널에서 옵니다([조사](research/initial-user-acquisition.md#ai-운영자가-혼자-할-수-있는-것과-없는-것)). AI 운영자는 계정을 만들거나 게시·발송하지 않습니다([헌장](../ops/ai-operator.md#어떤-경우에도-지킬-규칙) 1~3). 이 문서는 사람이 그대로 받아 실행할 문안, 실행 전에 확인할 규칙, 요청 목록과 결과 기록 자리를 한곳에 둡니다.

이 문서는 법률 자문이 아닙니다. 법·약관 해석은 조사 문서의 `(추론)`을 따르며 법률 검토 전입니다.

## 쓰는 방법

1. [사람 요청 목록](#사람-요청-목록)에서 위부터 하나를 고릅니다. 같은 주에 채널을 둘 이상 시작하지 않습니다(0087 전에는 채널별 효과를 가입 수 변화로만 보기 때문).
2. 그 채널의 [공통 규칙 확인표](#공통-규칙-확인표)와 채널별 확인 항목을 모두 확인합니다. 하나라도 `아니요`면 하지 않습니다.
3. 문안의 `<…>` 자리만 채우고, 사실(숫자·기능)은 바꾸지 않습니다. 문안은 지금 운영 기능 기준입니다. 기능이 바뀌면 AI 운영자가 이 문서를 고칩니다.
4. 실행한 날을 요청 목록 `실행일`에 적습니다. 사람이 적지 않으면 AI 운영자가 다음 실행에서 물어볼 수 없으므로(질문하지 않음), 실행 기록에서 7일 가입 수가 늘어난 날을 근거로 추정만 합니다.
5. 받는 사람의 이름·연락처·계정 주소는 이 문서·work item·실행 기록에 적지 않습니다([헌장](../ops/ai-operator.md#어떤-경우에도-지킬-규칙) 4). 개수만 적습니다.

## 크리링 사실(문안 근거)

문안은 아래 사실만 씁니다. 원본은 코드이며, 바뀌면 이 절과 문안을 함께 고칩니다.

| 사실 | 값 | 원본 |
| --- | --- | --- |
| 주소 | `https://links.shaul.kr` | 운영 주소 |
| 가입 | 구글 계정으로 시작 | 홈 `apps/web/src/app/(public)/page.tsx` |
| 무료 | 단축 주소, 주소 변경, 보이는 외부 링크 5개, 포트폴리오 20개, SNS 채널 10개 | `packages/shared/src/crelink.ts` `CRELINK_LIMITS` |
| 링크 슬롯 이벤트 | 관리 화면에서 신청하면 보이는 외부 링크 +5(기본 5 → 10), 계정당 한 번, 끝 날짜 미정 | PRD R24, 설계 `docs/specs/crelink-slot-event.md` |
| 무료 랜딩의 광고 | 링크 사이에 크리링 배너 자리 1개(지울 수 없음, 크리링 자신의 배너만) | PRD R20 |
| 사용 안내 | `https://links.shaul.kr/docs/guide`, 활용 글 `https://links.shaul.kr/docs/instagram-profile-links` | `apps/web/src/lib/docs.ts` |

쓰지 않는 표현: "기간 한정"·"마감 임박"(이벤트 끝 날짜를 정하지 않았음), "○○명이 쓰는"(실사용자 0명 기준), 다른 서비스 이름을 들어 낮추는 비교, "평생 무료"(정하지 않음).

## 채널별 문안

### 1. 지인 초대(1:1 메시지)

- 대상: 인스타그램 등에서 활동하고 프로필 링크가 필요할 만한, 이미 아는 크리에이터.
- 규칙: C1·C2·C7·C8. 단체방·여러 명에게 같은 글을 한꺼번에 보내지 않습니다. 먼저 물어보는 메시지(1-A)에 상대가 "보내 달라"고 답했을 때만 소개(1-B)를 보냅니다.
- 확인할 곳: 상대와의 대화 기록(동의 답장).

1-A 먼저 묻기:

```text
<이름>님, 요즘 잘 지내요? 제가 크리에이터용 프로필 링크 페이지 서비스를 직접 만들었는데, 인스타그램 프로필 링크 쓰시는 분 의견이 듣고 싶어서요. 소개 링크 하나 보내도 될까요? 괜찮지 않으면 편하게 말해 주세요.
```

1-B 소개(상대가 받기로 한 뒤):

```text
고마워요! 크리링이라는 서비스예요. SNS 채널·포트폴리오·외부 링크를 한 페이지에 모아서 짧은 주소 하나로 인스타그램 프로필에 걸 수 있어요.

- 구글 계정으로 1분 안에 시작: https://links.shaul.kr
- 단축 주소·주소 변경 무료, 외부 링크 5개 무료(지금 이벤트 신청하면 10개)
- 무료 페이지에는 링크 사이에 크리링 배너 자리가 하나 들어가요

써 보고 불편한 점 알려 주시면 바로 고칠게요. 관리 화면의 '의견 보내기'로 남겨도 돼요.
```

### 2. 디스콰이엇 제품 등록

- 대상: 메이커·초기 창업자 커뮤니티 [디스콰이엇](https://disquiet.io/announcement).
- 규칙: C3·C4·C6. 본인 제품만 등록하고, 등록은 디스콰이엇 검토 승인 뒤 보입니다. 같은 글을 여러 번 올리지 않습니다.
- 확인할 곳: 디스콰이엇 공지·제품 등록 화면의 운영 규칙(등록 직전 다시 확인).

제품 한 줄 소개:

```text
인스타그램 프로필 링크 하나로 SNS·포트폴리오·외부 링크를 모아 보여 주는 크리에이터 랜딩페이지
```

제품 설명:

```text
크리링은 크리에이터가 SNS 채널, 포트폴리오, 외부 링크를 한 페이지에 모아 짧은 주소로 전하는 랜딩페이지 서비스입니다. 혼자 만들고 있고, 첫 사용자 의견을 받으며 고치는 중입니다.

- 구글 계정으로 시작, 단축 주소와 주소 변경 무료
- 외부 링크 5개 무료, 링크 슬롯 이벤트를 신청하면 10개
- 무료 페이지에는 링크 사이에 크리링 배너 자리 1개가 들어갑니다

궁금한 점이나 불편한 점을 댓글로 남겨 주시면 고쳐서 릴리스 노트에 남기겠습니다.
https://links.shaul.kr
```

제품에 연결해 올리는 첫 글(메인 피드용):

```text
제목: 크리에이터 프로필 링크 페이지 '크리링'을 만들고 있어요

인스타그램 프로필에는 링크를 넣을 자리가 적어서, 협업 제안 받을 포트폴리오와 판매·공구 링크를 같이 보여 주기 어렵다는 이야기를 듣고 만들기 시작했어요. 지금은 링크·포트폴리오·SNS 채널을 한 페이지에 모으고, 짧은 주소로 프로필에 걸 수 있어요.

아직 사용자가 거의 없는 초기라, 써 보고 막히는 지점을 알려 주시면 가장 큰 도움이 됩니다. 만든 사람이 직접 올리는 글이에요.
```

### 3. 크리에이터·마케팅 커뮤니티 홍보 게시판

- 대상: 크리에이터·1인 사업자·마케터 카페나 커뮤니티 중 **홍보 게시판이 있거나 운영자가 허락한 곳**.
- 규칙: C3·C4·C6. 한 커뮤니티에 한 번만 올리고, 다른 게시판(자유·질문)에 홍보 글을 올리지 않습니다. 댓글로 남의 글에 홍보를 달지 않습니다.
- 확인할 곳: 그 커뮤니티의 공지·게시판 규칙(홍보 허용 게시판, 등급 조건, 글머리, 횟수 제한). 확인한 규칙을 요청 목록 `메모`에 커뮤니티 이름 없이 "홍보 게시판 허용, 월 1회" 식으로 적습니다.

게시 글:

```text
[홍보] 인스타그램 프로필 링크 페이지 '크리링' (만든 사람이 직접 올립니다)

인스타그램 프로필 링크 하나에 SNS 채널, 포트폴리오, 외부 링크를 모아 보여 주는 페이지를 만들었어요.

- 구글 계정으로 시작: https://links.shaul.kr
- 단축 주소·주소 변경 무료, 외부 링크 5개 무료(이벤트 신청 시 10개)
- 포트폴리오를 사진·설명과 함께 올려 협업 제안용 페이지로 쓸 수 있어요
- 무료 페이지에는 링크 사이에 크리링 배너 자리 1개가 들어가요

사용법: https://links.shaul.kr/docs/instagram-profile-links
초기라 불편한 점을 알려 주시면 바로 고치겠습니다. 이 게시판 규칙에 어긋나면 지우겠습니다.
```

`[홍보]`는 그 커뮤니티가 정한 글머리로 바꿉니다.

### 4. 크리링 공식 인스타그램 소개 게시물

- 선행: 크리링 공식 인스타그램 계정을 만들지는 사람이 정합니다(PRD `위험과 미정 사항`). 만들면 사람이 직접 만들고 직접 게시합니다. AI 운영자는 계정을 만들거나 로그인하지 않습니다([헌장](../ops/ai-operator.md#어떤-경우에도-지킬-규칙) 2). 공식 게시 API는 프로페셔널 계정과 Meta 앱 권한이 생긴 뒤 따로 정합니다.
- 규칙: C1·C4·C6. 하루 1개 이하로 올립니다. 팔로우·좋아요·태그를 이벤트 조건으로 걸지 않습니다. 다른 계정에 자동·대량 댓글·DM을 하지 않습니다.
- 확인할 곳: [Instagram 이용 약관](https://help.instagram.com/581066165581870/?locale=ko_KR), [Meta 스팸 정책](https://transparency.meta.com/ko-kr/policies/community-standards/spam/).
- 프로필 링크: `https://links.shaul.kr`. 이미지는 크리링 화면 캡처(시험 데이터, 실제 크리에이터 데이터는 허락 없이 쓰지 않음)나 기존 크리링 배너(`design/first-ad-banner/`, 0086)를 씁니다.

게시물 1(소개):

```text
인스타그램 프로필 링크, 하나로 충분하게.

크리링은 SNS 채널·포트폴리오·외부 링크를 한 페이지에 모아 짧은 주소로 전하는 크리에이터 랜딩페이지예요.
단축 주소와 주소 변경은 무료, 외부 링크도 5개까지 무료예요.

프로필 링크에서 구글 계정으로 시작해 보세요.
```

게시물 2(사용 3단계):

```text
크리링 시작은 세 단계예요.

1. 구글 계정으로 시작
2. 링크나 포트폴리오 하나 추가
3. 내 크리링 주소를 복사해 인스타그램 프로필 '링크'에 붙여 넣기

자세한 방법은 프로필 링크의 사용 안내에 있어요.
```

게시물 3(이벤트):

```text
링크 슬롯 이벤트를 하고 있어요.

관리 화면에서 이벤트를 신청하면 보이는 외부 링크가 5개 더 늘어나요(5개 → 10개). 계정당 한 번, 신청만 하면 돼요.
팔로우나 좋아요는 필요 없어요.
```

## 결과 재기

- 원본 지표: `node scripts/ai-operator.mjs context`(API `GET /api/admin/metrics`)의 실사용자 수, 가입 24시간·7일, 방문 7일.
- 유입 경로 기록(0087)이 생기기 전: 채널을 한 주에 하나만 시작하고, 실행일 앞 7일과 뒤 7일의 가입 수·실사용자 수 차이를 그 채널의 결과로 봅니다(같은 주의 다른 변화와 섞이므로 추정치).
- 0087이 생긴 뒤: 문안의 주소를 채널별 경로값을 붙인 주소로 바꿉니다. 제안 값은 `friend`(H1), `disquiet`(H3), `community`(H4), `instagram`(H5)이며, 실제 형식은 0087 결정을 따릅니다. 0087 전에는 경로값을 붙이지 않습니다(기록되지 않는 값을 붙이면 주소만 길어짐).
- 단계 판단은 [조사의 단계별 가설과 지표](research/initial-user-acquisition.md#실사용자-100명까지-단계별-가설과-지표)를 따릅니다.
