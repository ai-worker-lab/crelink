# Instabio 가져오기 PRD

- 상태: 확정
- 작성일: 2026-11-06
- 관련 work item: [0197](../work/orchestrator/0197-instabio-import.md)

## 문제와 요구

사용자가 제공한 Instabio 페이지를 크리링으로 옮길 수 있는 기능을 요청했다.

| 번호 | 요구 | 상태 | 수용 기준 |
| --- | --- | --- | --- |
| R1 | 공개 Instabio 페이지 내용을 크리링으로 가져온다 | [사용자 확정] | 제공 페이지의 상품 링크 11개·순서·제휴 URL·썸네일·프로필 소개를 보존할 수 있다 |

## 사용자 흐름과 구현 판단

기존 페이지 편집 → 외부 링크 → Instabio에서 가져오기 → URL 입력 → 미리보기 → 항목 선택·제목 수정 → 저장. 기존 링크는 보존하고 뒤에 추가한다. 같은 URL은 건너뛴다. 이름·소개·프로필 사진 교체는 별도 체크하며 기본 해제한다. 저장하면 방문자에게 바로 보인다는 안내를 둔다. 이는 R1을 안전하게 구현하기 위한 판단이며 별도 사용자 결정으로 기록하지 않는다.

## 조사·범위

2026-11-06 실제 공개 페이지와 공개 CDN JSON을 확인했다. 원본 [Instabio 페이지](https://instabio.cc/4122903dwCwrV)는 JavaScript로 버튼 링크를 표시한다. 공개 데이터만 읽으며 로그인·추적 스크립트·제휴 링크 방문은 필요하지 않았다. 원시 응답의 추적 필드·이메일 해시·키는 저장하지 않는다.

기존 수동 링크 추가를 재사용하며 새 라이브러리·브라우저 실행 서버·외부 가져오기 SaaS는 도입하지 않는다. 다른 제공자·디자인 복제·통계 이전·예약/잠금 링크·여러 페이지 가져오기는 범위 밖이다. 원본 변경이나 지원하지 않는 구조는 오류/제외 안내로 드러낸다. 기술·검증 기준은 [설계](../specs/instabio-import.md)에 있다.
