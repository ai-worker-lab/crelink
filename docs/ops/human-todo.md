# 사람 비용 승인과 접근·보안 지원

2026-10-12 사용자 결정(“외부 홍보도 자체적으로 하라. 지출, 결제만 사람 승인 필수로 한다”)에 따라 사전 사람 결정 대기는 실제 지출·결제·유료 구독/크레딧·비용 발생 약정만입니다. 무료 외부 홍보·회사 계정 구성·제품 결정은 [헌장](ai-operator.md)에 따라 PM이 자율 실행합니다. 이 문서의 접근·보안 지원은 기술 전제/운영 통제이며 일반 홍보 승인 게이트가 아닙니다. 법·약관·수신동의·개인정보·저작권·사칭/스팸 금지와 인증·멈춤·데이터 파괴 금지는 사람 승인으로 우회할 수 없습니다.

- **사람**: 비용 승인에는 대상·금액·범위·조건을 적습니다. 지원을 끝낸 항목은 `[x]`로 바꾸고 실제 날짜를 적고, 하지 않기로 했으면 `안 함`과 이유를 적습니다. 기존 완료 기록은 보존합니다.
- **PM**: 비용이 실제 발생하는 행동만 사전 승인 요청으로 추가합니다. 무료 여부 미확인은 조사 상태이며 0으로 쓰지 않습니다. 접근 불가는 연결한 원본 work item에 실패 단계·필요한 정상 접근 조건을 기록합니다. 사람 계정/credentials 전달·공개, CAPTCHA/OTP 우회나 사칭을 요청하지 않습니다. 원본 work item에서 실제 결과를 확인한 뒤 기록하며 미확인 완료를 추정하지 않습니다.

## 1. 접근·보안과 운영 기반 지원(승인 대기 아님)

AI 운영자에게 모든 권한을 위임하면서 받아들인 위험([ADR 0015](../adr/0015-ai-operator.md) `결과와 트레이드오프`)을 줄이는 기존 지원 목록입니다. 실제 사람 자격·기기 관리가 필요한 기술 전제와 멈춤 통제는 유지하되 무료 홍보의 허락을 받는 목록으로 사용하지 않습니다.

- [ ] **AI 전용 GitHub 계정 만들기**: machine user를 만들어 저장소 협업자로 추가하고, 운영자 Mac에서 AI 실행에 쓰는 `gh auth`를 그 계정으로 바꿉니다. 그전까지 AI는 사람의 `gh` 자격으로 커밋·머지하고, 커밋 트레일러로만 구별됩니다. 근거: 헌장 [실행 환경 설치](ai-operator.md#실행-환경-설치사람이-한-번) 4.
- [ ] **AI 실행 계정 분리**: Orca 자동화 `crelink-ai-operator`를 SSH 키·`sudo`·사람 `gh`·키체인이 없는 별도 macOS 사용자(또는 VM)로 옮기고, `~/.config/crelink/ai-operator.env`는 그 사용자 홈으로 옮깁니다. 이 일을 끝내기 전까지는 AI가 사람 자격으로 토큰 발급·멈춤 해제를 할 수 있고, 헌장 규칙으로만 막습니다. 근거: 헌장 실행 환경 설치 6.
- [ ] **CODEOWNERS와 보안 변경 통제 검토**: 기존 제안은 인증·AI 운영자·migration·`docs/ops/**`·`.github/**` 변경의 사람 승인 요구였고 AI 전용 GitHub 계정 뒤에 효과가 있습니다. 현 정책에서는 일반 변경·홍보 재승인 게이트가 아니라 인증·멈춤·데이터 보호 통제로 PM이 검토합니다. 실제 사람 자격이 필요한 설정만 정상 접근 지원으로 분리합니다. 근거: 헌장 실행 환경 설치 7.
- [ ] **시험 계정 지표 제외**: 운영자 화면 `/admin` → 크리에이터 상세에서 본인·지인 시험 계정에 `지표 제외`를 켭니다. 이 스위치는 사람 운영자만 바꿀 수 있습니다. 실사용자 지표(PRD `목표`)를 정확하게 셉니다.
- [ ] **운영자 Mac 기본 Node를 24로**: 지금 기본은 v22라 AI 실행이 매번 우회합니다(첫 실행 기록 `1827dbad`의 다음 할 일). `nvm alias default 24.20.0`으로 바꿉니다. Node 버전 기준은 [로컬 개발 환경](../development/local-environment.md)에 있습니다.
- [x] **AI 운영자 토큰과 20분 Orca 자동화 설치**(2026-10-11): 제2 AI 계정 `ai-operator-2@crelink.invalid`의 토큰을 `~/.config/crelink/ai-operator-2.env`(권한 600)에 저장하고 `crelink-ai-operator-2` 자동화를 `Asia/Seoul` `*/20 * * * *`로 활성화했습니다. precheck와 첫 예약 실행·실행 기록을 확인했습니다. 토큰 원문은 남기지 않았습니다. 상세: [0157](../work/orchestrator/0157-second-ai-operator.md).
- [ ] **운영자 Mac 켜 두기**: 20분 실행은 운영자 Mac에서 돕니다. 꺼지거나 잠자거나 VPN·exit node로 나가면 그 주기는 빠집니다(Cloudflare 차단). 노트북이면 뚜껑을 닫았을 때 잠자지 않게 하거나 전원에 연결해 둡니다. 근거: 헌장 실행 환경 설치 2·5.

## 2. 실사용자 모집(목표 100명): PM 실행으로 전환

기존 H1~H5 사람 요청(2026-10-10)은 2026-10-12부터 [모집 채널 PM 실행 목록](../product/acquisition-playbook.md#pm-실행-목록)과 [0153](../work/product/0153-acquisition-human-requests.md)의 PM 소유 작업입니다. 사람 실행/계정 개설/일반 홍보 허락을 기다리지 않습니다. 기존 문안·요청일·미기록 실행일과 Google 계정 선정(2026-10-10) 등 과거 근거는 원본에 보존했습니다. 이 전환은 외부 게시 완료가 아닙니다.

- **H1**: 회사 발신 접근과 이미 적법하게 받은 사전 광고 수신동의가 있는 경우만 PM이 개별 실행합니다. 무동의 “소개해도 될까요?” 연락(1-A)도 보내지 않습니다.
- **H2**: PM이 회사 Google·네이버 계정 접근·소유 확인 전제를 확인하고 Search Console/서치어드바이저 등록을 실행합니다. 정상 접근/인증 불가는 비용 승인 대기가 아니라 blocker로 기록합니다. 원본: [0148](../work/orchestrator/0148-search-console-registration.md).
- **H3·H4**: 허용된 무료 제품 등록·공개 홍보 게시판을 PM이 선정·실행하며, 채널 검토 제출과 실제 공개를 구분합니다.
- **H5**: PM이 플랫폼이 허용하는 무료 공식 인스타그램 회사 계정 구성과 게시를 결정하고 PRD에 근거를 남깁니다. 사람 개인계정이나 우회 인증을 사용하지 않습니다.

## 3. 지출·결제 사전 승인

유료 광고·유료 구독/크레딧·현금/선물 보상·비용 발생 약정을 실제로 진행할 때만 PM이 대상·금액·기간·약정/갱신 조건·근거와 연결한 work item을 여기 추가하고 사람 승인 전에 실행하지 않습니다. 현재 이 문서에 기록된 구체적인 비용 승인 요청은 없습니다. 무료 게시·회사 계정 구성, 비용 없는 새 슬롯·이벤트 조건, 일반 법률·제품 판단은 이 절의 승인 대상이 아닙니다.

### 기존 제품·법률 검토 전제(사람 승인 요청에서 전환)

- **개인정보 처리방침에 로컬 저장 고지 한 줄 추가 여부**: 관리 화면 시작 안내 카드의 진행 표시는 브라우저에만 저장됩니다. PM이 제품/개인정보 검토로 결정하고 근거를 원본에 남깁니다. [0152](../work/web/0152-privacy-local-progress-notice.md)
- **법률 검토 상태**: 이용약관, 개인정보 처리방침, 광고 블록 안내, 모집 문안(광고성 정보, 추천·보증 표시)은 기존 기록상 법률 검토 전입니다. 일반 사람 허락으로 이를 충족한 것으로 보지 않습니다. PM은 실행 전 법·약관 준수 근거를 확인하며, 근거가 부족한 행동은 하지 않습니다. 외부 유료 법률 자문 비용이 필요하면 비용만 사전 승인 요청으로 분리합니다. 근거: [초기 사용자 모집 조사](../product/research/initial-user-acquisition.md#지켜야-할-법과-약관).

## 4. 정기 운영 지원과 멈춤 통제(승인 대기 아님)

- **AI 운영자 토큰 회전**: [런북 17-5](../../infra/docs/prod-runbook.md#17-5-회전) 순서대로 합니다. 지금 토큰 label은 `operator-mac-2026-10`입니다. 주기는 아직 정하지 않았고, label 이름에 맞춰 월 1회를 제안합니다. 유출이 의심되면 바로 [17-6](../../infra/docs/prod-runbook.md#17-6-실패유출-처리)을 따릅니다.
- **주 1회 AI 실행 훑어보기**: 운영자 화면 `/admin/agent-runs`(실행 기록)와 `/admin/actions`(운영 기록)를 봅니다. 이상하면 멈춤 스위치를 켜고, 진행 중인 머지·배포까지 막으려면 Orca 자동화도 끕니다(헌장 [멈추기와 복구](ai-operator.md#멈추기와-복구)).
