# 사람이 할 일

AI 운영자([헌장](ai-operator.md))는 사람 계정·사람 결정·사람 자격이 있어야 하는 일을 할 수 없습니다. 그런 일을 이 목록 한 곳에 모읍니다.

- **사람**: 끝낸 항목은 `[x]`로 바꾸고 날짜를 적습니다. 하지 않기로 했으면 `[x]`에 `안 함`과 이유를 적습니다. 휴대폰에서는 GitHub 저장소 화면에서 이 파일을 열어 봅니다.
- **AI 운영자**: 사람 결정이 필요한 일이 생기면 이 목록의 맞는 절에 한 줄을 더합니다(헌장 [사람에게 알리기](ai-operator.md#사람에게-알리기)). 세부와 진행 상태의 원본은 연결한 work item이나 문서이고, 이 목록에는 할 일과 링크만 둡니다. 사람이 끝냈다고 적은 항목은 다음 실행에서 결과를 확인해 연결한 work item에 기록합니다.

## 1. 보안과 운영 기반

AI 운영자에게 모든 권한을 위임하면서 받아들인 위험([ADR 0015](../adr/0015-ai-operator.md) `결과와 트레이드오프`)을 줄이는 일입니다. 위에서부터 합니다.

- [ ] **AI 전용 GitHub 계정 만들기**: machine user를 만들어 저장소 협업자로 추가하고, 운영자 Mac에서 AI 실행에 쓰는 `gh auth`를 그 계정으로 바꿉니다. 그전까지 AI는 사람의 `gh` 자격으로 커밋·머지하고, 커밋 트레일러로만 구별됩니다. 근거: 헌장 [실행 환경 설치](ai-operator.md#실행-환경-설치사람이-한-번) 4.
- [ ] **AI 실행 계정 분리**: Orca 자동화 `crelink-ai-operator`를 SSH 키·`sudo`·사람 `gh`·키체인이 없는 별도 macOS 사용자(또는 VM)로 옮기고, `~/.config/crelink/ai-operator.env`는 그 사용자 홈으로 옮깁니다. 이 일을 끝내기 전까지는 AI가 사람 자격으로 토큰 발급·멈춤 해제를 할 수 있고, 헌장 규칙으로만 막습니다. 근거: 헌장 실행 환경 설치 6.
- [ ] **CODEOWNERS와 사람 승인**: 인증·AI 운영자·migration·`docs/ops/**`·`.github/**` 변경에 사람 승인을 요구합니다. AI 전용 GitHub 계정을 만든 뒤에 효과가 있습니다. 근거: 헌장 실행 환경 설치 7.
- [ ] **시험 계정 지표 제외**: 운영자 화면 `/admin` → 크리에이터 상세에서 본인·지인 시험 계정에 `지표 제외`를 켭니다. 이 스위치는 사람 운영자만 바꿀 수 있습니다. 실사용자 지표(PRD `목표`)를 정확하게 셉니다.
- [ ] **운영자 Mac 기본 Node를 24로**: 지금 기본은 v22라 AI 실행이 매번 우회합니다(첫 실행 기록 `1827dbad`의 다음 할 일). `nvm alias default 24.20.0`으로 바꿉니다. Node 버전 기준은 [로컬 개발 환경](../development/local-environment.md)에 있습니다.
- [ ] **운영자 Mac 켜 두기**: 30분 실행은 운영자 Mac에서 돕니다. 꺼지거나 잠자거나 VPN·exit node로 나가면 그 주기는 빠집니다(Cloudflare 차단). 노트북이면 뚜껑을 닫았을 때 잠자지 않게 하거나 전원에 연결해 둡니다. 근거: 헌장 실행 환경 설치 2·5.

## 2. 실사용자 모집(목표 100명)

문안·규칙 확인표·순서는 [모집 채널 실행 문안](../product/acquisition-playbook.md#사람-요청-목록)에 있고, 실행일·결과는 그 표에 적습니다. 진행 관리는 [0153](../work/product/0153-acquisition-human-requests.md)입니다. 한 주에 하나씩 권합니다.

- [ ] **H1 지인 초대**: 아는 크리에이터 5명에게 1-A 문안으로 묻고, 받기로 한 사람에게만 1-B를 보냅니다. 동의 없이 단체로 보내지 않습니다(정보통신망법 제50조).
- [ ] **H2 검색엔진 등록**: Google Search Console(계정은 정함)과 네이버 서치어드바이저에서 `https://links.shaul.kr/` 소유 확인용 HTML 태그 값을 받아 AI 운영자에게 알려 줍니다. 태그가 배포되면 `확인`을 누르고 sitemap `https://links.shaul.kr/sitemap.xml`을 제출합니다. 네이버 계정은 아직 정하지 않았습니다. 진행: [0148](../work/orchestrator/0148-search-console-registration.md).
- [ ] **H3 디스콰이엇 제품 등록과 첫 글**: H1 1주 뒤, 받은 의견을 반영한 다음에 합니다.
- [ ] **H4 커뮤니티 홍보 게시판 1곳에 게시**: H3 1주 뒤에 합니다.
- [ ] **H5 크리링 공식 인스타그램**: 계정을 만들지 정합니다. 만들면 게시물 1~3을 하루 1개씩 올립니다. 결정은 PRD `위험과 미정 사항`에 반영합니다.

## 3. 결정 대기

- [ ] **개인정보 처리방침에 로컬 저장 고지 한 줄 추가 여부**: 관리 화면 시작 안내 카드의 진행 표시는 브라우저에만 저장됩니다. [0152](../work/web/0152-privacy-local-progress-notice.md)
- [ ] **법률 검토**: 이용약관, 개인정보 처리방침, 링크 슬롯 이벤트 조건, 모집 문안(광고성 정보, 추천·보증 표시)은 모두 법률 검토 전입니다. 근거: [초기 사용자 모집 조사](../product/research/initial-user-acquisition.md#지켜야-할-법과-약관).

## 4. 정기

- **AI 운영자 토큰 회전**: [런북 17-5](../../infra/docs/prod-runbook.md#17-5-회전) 순서대로 합니다. 지금 토큰 label은 `operator-mac-2026-10`입니다. 주기는 아직 정하지 않았고, label 이름에 맞춰 월 1회를 제안합니다. 유출이 의심되면 바로 [17-6](../../infra/docs/prod-runbook.md#17-6-실패유출-처리)을 따릅니다.
- **주 1회 AI 실행 훑어보기**: 운영자 화면 `/admin/agent-runs`(실행 기록)와 `/admin/actions`(운영 기록)를 봅니다. 이상하면 멈춤 스위치를 켜고, 진행 중인 머지·배포까지 막으려면 Orca 자동화도 끕니다(헌장 [멈추기와 복구](ai-operator.md#멈추기와-복구)).
