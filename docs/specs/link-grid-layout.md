## 최소 구성과 호환

list 기본값의 CHECK 컬럼1개를 추가한다. shared 필드는 Blue/Green 이전 API·기존 소비자와 공존하도록 선택 필드로 두고 미수신은 list로 처리한다. 기존 PATCH만 확장하고 새 경로/패키지를 만들지 않는다. 본인 userId 조건을 유지하며 프로필/가져오기는 표시 방식을 건드리지 않는다. 설정은 선택 즉시 미리보기와 저장에 반영하고 실패하면 표시 방식만 복구한다. 저장 중 전환/이탈은 기존 공통 pending으로 막는다.

## 시각·상호작용

기존 토큰과 링크 컴포넌트를 사용한다. 그리드는320px 이상에서3열, 위쪽1:1 이미지 영역(object-fit:contain)과 아래 제목/설명이다. 사진이 없으면 기존 사이트/링크 아이콘을 같은 이미지 영역에 둔다. 제목을 잘라 없애지 않고 줄바꿈한다. 배너는 grid-column 전체로 보존하고 DOM 순서/계측/클릭 주소/숨김·차단 규칙은 유지한다. 관리 정렬 목록은 그대로 두며 방문자 전환 버튼은 없다. 빈 링크 상태와 설정 저장중/오류/성공, 접근 가능한 라디오·44px 조작영역을 제공한다.

## 검증·역할 검토

API/DB 실제 HTTP: 기본값·list/grid 영속성·엄격한 입력·타인 격리·공개 계약·기존 프로필 보존. 미리보기 변환 테스트,320/390/768/1280 화면·사진 유무/긴 제목/홀수 배너·클릭/저장 실패, 실제 브라우저와 영향 범위 검증을 수행한다. 기술 설계 스킬에 따라 API와 웹/디자인 검토를 읽기 전용으로 위임한다. 새 인프라 의존은 없다.

## 검토 기록

- API 검토: 이전 API가 새 필드를 무시해200을 줄 수 있어 PATCH 응답의 실제 linkLayout이 요청값과 일치할 때만 성공 처리한다.
- 웹/디자인 검토: 공통 pending·한 필드만 복구·공개/미리보기 전용 CSS·라디오 접근성·배너 전체 열/DOM 순서 유지와 사진 없는 대체 표시를 반영한다.
