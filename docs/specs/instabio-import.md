## 계약과 처리

로그인 SessionGuard와 기존 BFF Origin 검사를 따른다. 미리보기는 `{url}` → `{sourceUrl, fingerprint, profile, links, warnings}`이며 DB를 바꾸지 않는다. 저장은 URL·fingerprint·선택한 항목 id/수정 제목·프로필 교체 여부를 받는다. 서버가 공개 데이터를 다시 읽고 해시가 다르면 409 `import_source_changed`로 다시 미리보기를 요청한다. 클라이언트가 보낸 이미지/목적 URL은 사용하지 않는다. 선택 id는 원본 순서로 적용하며 기존 URL·한 요청 안 중복은 건너뛴다. 응답은 커밋된 추가 링크·중복 수·적용한 프로필이다. 화면은 이 결과를 먼저 반영하고 최신 상태를 별도로 재조회한다. 프로필 교체는 landings 행 잠금 안에서 요청의 기존 프로필 스냅샷과 비교한다.

이미지는 고정 CDN upload 경로에서만 받아 기존 FilesService의 매직 바이트/4MB 제한을 적용하고 자사 저장소에 복사한다. 외부 다운로드를 DB 잠금 전에 끝내며 링크·선택한 프로필 변경은 사용자 행 잠금 아래 한 트랜잭션으로 저장한다. 한도50·차단 도메인·본인 소유 파일 검증을 재사용한다. 실패하면 링크·프로필은 원상태다. 이미지 준비는 기존 업로드와 같은 독립 파일 저장이므로 저장 실패 후 미참조 업로드가 남을 수 있다(자동 정리 보장 없음). 스키마 변경은 없다.

## 보안과 자원 제한

입력은 `https://instabio.cc/<영숫자 id>`만 허용한다. 쿼리/fragment는 제거한다. 인증정보·비기본 포트·다른 호스트·redirect는 거절한다. CDN 데이터 URL은 검증한 id로 고정 생성하고, 이미지 URL은 `https://bio.linkcdn.cc/upload/<영숫자>/<숫자>/<숫자>.(jpg|jpeg|png|webp|gif)`만 허용한다. 원본 스크립트는 실행하지 않고 정해진 inline JSON과 CDN JSON만 JSON.parse한다. 목적 URL은 http/https와 길이만 검증하며 요청하지 않는다. 문서당 1MB, 이미지당4MB·전체32MB, 요청 timeout과 동시 다운로드3개 제한. 동시 가져오기는 계정당1회/process, 전체4회/process까지 허용하고 429 `import_busy`로 재시도 안내한다. 외부 연결/구조 오류는 422 `import_unavailable`로 반환하며 원문·추적값을 로그/응답에 싣지 않는다.

## 화면·디자인 검토

기존 폼·버튼·notice·details를 쓰며 새 토큰은 만들지 않는다. 미리보기 전/로딩/빈 항목/제외 경고/한도 초과/실패/완료 상태를 표현한다. 체크박스와 버튼의 터치영역44px, 입력16px, URL 줄바꿈·min-width:0, 320/390/1280 폭을 확인한다. 원본 이미지 미리보기는 public CDN을 직접 읽고 저장 시 복사한다. 프로필 초안이 있으면 프로필 교체를 막고 먼저 저장/취소 안내한다. 저장 후 링크/미리보기를 동기화하되 이미 확정된 저장을 조회 실패 때문에 미저장으로 알리지 않는다.

## 분해·검증

기존 모델 안 독립 기능이므로 orchestrator 0197 하나에서 계약 → API → 웹 → 통합 검증을 순차 수행한다. API/웹·디자인 검토는 읽기 전용으로 병렬 위임한다. API 단위/HTTP 회귀는 URL 경계·JSON 구조·조건부 링크 제외·순서·이미지·인증·계정 격리·중복/동시/한도·실패 원자성을 검증한다. 실제 제공 URL로 로컬 가져오기와 재시도, 데스크톱·모바일 화면/콘솔을 확인한다. 영향 범위에 맞춰 `pnpm verify`, smoke 및 가져오기 E2E를 실행한다. 실제 iOS Chrome은 에뮬레이션과 구분한다.
