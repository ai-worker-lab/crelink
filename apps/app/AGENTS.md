# 모바일 앱 작업 규칙

적용 범위: `apps/app/`와 그 하위 파일. [루트 공통 규칙](../../AGENTS.md)을 함께 따르며 여기서는 모바일 앱에 필요한 규칙만 정의합니다.

- Expo + React Native + Expo Router의 기존 구성을 기준으로 확장합니다. Expo SDK와 호환되는 네이티브 패키지 버전을 사용합니다.
- 브라우저 전용 API나 DOM 컴포넌트를 네이티브 코드에 그대로 사용하지 않습니다. 공통 로직과 플랫폼별 UI를 구분하고, 공유를 위한 추상화를 기능보다 먼저 만들지 않습니다.
- `design/`의 승인된 화면·토큰·에셋은 모바일 시각 표현의 기준 정보원입니다. 디자인을 앱 소유 React Native 코드/자산으로 옮기고 디자인 도구 내부 파일을 런타임에서 직접 불러오지 않습니다. 화면 동작과 데이터는 실제 API 계약에 연결하며 서버 업무 규칙을 앱에서 복제하지 않습니다.
- 네이티브 기능은 Expo Go 지원 여부와 개발 빌드 필요 여부를 구분합니다. 권한·안전 영역·키보드·뒤로 가기 같은 플랫폼 동작을 영향 범위에 맞춰 확인합니다.
- 실제 기기에서 `localhost`는 개발자 PC가 아닙니다. API 연결을 도입할 때 시뮬레이터·에뮬레이터·실기기의 주소와 네트워크를 구분합니다.
- `EXPO_PUBLIC_*`는 공개 설정이며 서명·배포 자격 증명과 앱 런타임 값을 분리합니다. [환경과 비밀값 관리](../../docs/development/environment-secrets.md)를 따릅니다.
- Metro 실행·번들 생성 성공은 실기기 검증을 대신하지 않습니다. 검증한 플랫폼과 시뮬레이터·실기기 여부, 확인하지 못한 범위를 구체적으로 보고합니다.
- 앱 전용 가이드는 `apps/app/docs/`에 둡니다.
- 앱 변경은 공개 여부와 관계없이 이 영역의 `CHANGELOGS.md`에 기록합니다. 기록 형식과 공개 릴리스 노트는 [공통 변경 기록 규칙](../../docs/development/repository-policy.md#변경-기록)을 따릅니다.
