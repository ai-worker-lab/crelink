# [Frontend Contract] 본인 방문 표시 최신 main 통합

## 구현 범위

- 기존 `AnalyticsDashboard.tsx` 구현을 유지합니다. 페이지뷰·익명 순 방문자와 일별 표에 집계 건수만 `본인 N`으로 표시하며 합계는 차감하지 않습니다. 첫 표시 전·보존 집계 혼합 구간은 null로 구분합니다.
- 현재 BFF의 `lib/api/backend-rules.ts`에 `ownerSession`을 연결해 랜딩 이벤트에만 로그인 세션을 전달합니다. 가입 경로 익명 수집·페이지 권한 헤더·Instagram IP 전달은 유지합니다.
- API·공유 계약의 `ownerVisits`·일별 owner 건수를 사용합니다. 응답에 세션·사용자 ID·방문자 ID·IP 원문을 추가하지 않습니다.

## 검증 계약

- 웹 단위·BFF 회귀: 공유 패키지 build 후 웹 test. 2026-11-11 통합 준비 중 165건 통과했으며 최종 main·의존성 통합 뒤 전체 CI로 재확인합니다.
- 실제 화면: 로컬 CI의 ego analytics-responsive가 익명 방문 → 본인 세션 방문 → 크리에이터·운영자 지표/통계 조회를 실행합니다. 합계 유지, 본인 1 뱃지, 과거 빈 기간 뱃지 없음과 기존 반응형·콘솔 검사를 확인합니다.
- 추가 엔진과 주요 사용자 흐름은 수동 GitHub CI로 확인합니다. 실행 전에는 통과로 기록하지 않습니다.
