# 원격 개발 환경

**현재 상태: 원격 자원과 배포 설정이 구성되지 않았습니다.** 이 폴더는 로컬과 분리된 통합·배포 확인 환경을 위한 위치입니다. 현재 실행할 Compose·배포 명령은 없습니다.

## 구성 전 필요한 정보

- 운영 자원과 분리된 DB·캐시·실행 서버 또는 서비스, 프로젝트 식별자
- 웹·API의 개발 도메인, TLS와 접근 제한 방식
- 배포할 브랜치·이미지·아티팩트 및 환경별 배포 계정
- 비밀값 주입 수단과 회수·교체 권한

prod 데이터와 운영 비밀값을 공유하지 않습니다. 테스트 데이터는 별도로 만들고, 같은 서버를 공유해야 한다면 프로세스·네트워크·볼륨·계정 격리를 먼저 설계합니다. 원격 대상이 정해지면 실제 설정과 그 검증 결과를 이 영역에 반영합니다.

공통 비밀값 원칙은 [환경과 비밀값 관리](../../docs/development/environment-secrets.md), 작업 규칙은 [인프라 AGENTS.md](../AGENTS.md)를 따릅니다.
