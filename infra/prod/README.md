# 운영 환경

**현재 상태: 배포되지 않았으며 실행 가능한 원격 배포 설정이 없습니다.** 목표 플랫폼과 미결정 항목은 [배포 대상 아키텍처](../../docs/architecture/deployment-target.md)가 기준입니다.

## 구성 전 필요한 정보

- 웹·API·DB 호스팅 대상과 프로젝트·서버 식별자, 접근 방식
- 도메인·TLS, API 배포 방식과 네트워크 접근 정책
- 캐시 제품·배치 위치·자원 제한
- 비밀값 주입, DB 마이그레이션 실행 권한, 백업·복구·배포 복구 절차

운영 환경은 local/dev와 DB·계정·비밀값을 공유하지 않습니다. 로컬 기본 계정이나 로컬 Compose를 그대로 원격 서버에 복사하지 않습니다. 자원 생성·데이터 삭제·서비스 중단을 일으키는 명령은 대상 환경과 영향을 확인한 뒤 실행합니다.

서버의 환경 파일을 사용하게 되더라도 이 폴더에는 실제 비밀값을 저장하지 않습니다. 관리 원칙은 [환경과 비밀값 관리](../../docs/development/environment-secrets.md), 작업 규칙은 [인프라 AGENTS.md](../AGENTS.md)를 따릅니다.
